Series. The shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

## Pack structure

Follows the era's pack template ([eras/ex.md](eras/ex.md#pack-contents)):
9 cards per pack, 36 packs per box (a web search confirms 36 packs per
box for this set). **Confidence: community estimate** for the common
and uncommon split; the era's two conflicting source counts (5/2 vs.
4/3) both remain open for this set.

confirmation.

## Special subsets and mechanics

- **Rare Holo ☆.** Regice ☆, Regirock ☆, Registeel ☆
  ([eras/ex.md](eras/ex.md#sets-that-break-the-template)).
- **δ Delta Species.** The set's one Secret Rare, Pikachu δ, uses a
  Metal-type energy print instead of Pikachu's usual Lightning type
  (Bulbapedia). No other δ Delta Species card in this set was found in
  a fetched source.
- **Reverse Holofoil.** Bulbapedia: this set's Reverse Holofoil pattern
  is a cosmic pattern.
- **God packs:** no source found. Confidence: unknown.
