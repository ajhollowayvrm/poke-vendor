# Evolving Skies (2021)

Set data for Evolving Skies. See [../13-sets.md](../13-sets.md) for the
approach. See [eras/sword-shield.md](eras/sword-shield.md) for the era
template and the evidence behind the pack order.

## Release

- English release: August 27, 2021.
- Set code: SWSH7. Abbreviation: EVS. TCGplayer set code: SWSH07.
- Cards: 237 total. 203 in the main numbering, plus 34 secret rares.

## Pack structure

- Bulbapedia: "Each Evolving Skies booster pack contains ten cards from the
  expansion, a basic Energy card, and a code card for use in the Pokémon
  Trading Card Game Online."
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo,
  1 rare or higher.
- TCGplayer: "there's only one slot in each pack—the rare slot—that might
  contain anything fancier than a Holo Rare."

## Pack order

**Confidence: community guide.** PokePatch names Evolving Skies for the
4-card Sword and Shield trick. NinePocket lists it under the same method.

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo |
| 7 | Rare slot |
| 8 | Basic Energy |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- With the community pack trick, the rare is last.
- Which end faces the wrapper front: Searched 2026-09-12: no source found (see the era file, which also resolves the code card's physical position).
