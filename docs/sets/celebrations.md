# Celebrations (2021)

Set data for Celebrations, a special expansion for the 25th anniversary. See
[../13-sets.md](../13-sets.md) for the approach. See
[eras/sword-shield.md](eras/sword-shield.md) for the era template.
**This set breaks the era template.**

## Release

- English release: October 8, 2021.
- Set code: CEL25. Abbreviation: CEL. TCGplayer set code: CLB.
- Cards: 50 total. 25 in the main numbering (including 1 secret rare, Mew
  025/025), plus 25 Classic Collection cards.

## Pack structure

- Bulbapedia: "Each Celebrations booster pack contains four cards".
- TCGplayer: "Each Celebrations booster pack contains 4 random cards."
- SlashGear: each pack has "one chance for a sub-set card, and at least
  three will be from the base set". A pack holds 4 base-set cards, or 3
  base-set cards plus 1 Classic Collection card. A pack never holds more
  than 1 Classic Collection card.
- Energy card: Unknown. Code card: Unknown.
- Bulbapedia: "There is no Reverse Holo parallel set for Celebrations".
- The set list has no commons and no uncommons.

## Pack order

**Confidence: Unknown.**

- No source describes the order of the 4 cards.
- NinePocket lists Celebrations under the 4-card Sun & Moon to Sword & Shield
  method. That method cannot apply to a 4-card pack as written. Treat this as
  a conflict, not as data.
- Where the hit sits: Unknown. Every card in the set is Rare or higher, so
  every card is a hit under the rarity rule in
  [../18-ripping.md](../18-ripping.md#what-counts-as-a-hit).

## Special subsets or mechanics

- Classic Collection: 25 close replicas of famous older cards, with etching
  and a Confetti Holofoil pattern. They keep their original numbers.
- No booster box. Packs came only in set products. Most products also hold
  other Sword & Shield Series packs.
