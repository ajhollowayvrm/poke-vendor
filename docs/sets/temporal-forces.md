# Temporal Forces (2024)

Set data for Temporal Forces. The shared pack template, pack order, and rarity
system are in [eras/scarlet-violet.md](eras/scarlet-violet.md). This file
records the set data and every exception. See [../13-sets.md](../13-sets.md)
for the general approach.

## Release

- **English release:** March 22, 2024.
- **Set code:** TEF.
- **Card count:** 218 cards. The main set has 162 cards. The secret rares are
  56 cards, numbered 163/162 to 218/162.

| Part | Rarity | Cards |
|---|---|---|
| Main set | Common | 71 |
| Main set | Uncommon | 55 |
| Main set | Rare | 14 |
| Main set | Double Rare | 15 |
| Main set | ACE SPEC Rare | 7 |
| Secret rares | Ultra Rare | 18 |
| Secret rares | Illustration Rare | 22 |
| Secret rares | Special Illustration Rare | 10 |
| Secret rares | Hyper Rare | 6 |

The counts come from the Bulbapedia set list. TCGplayer gives the same
counts.

## Pack structure

12 cards per pack: 10 set cards, 1 Basic Energy card, and 1 code card.

| Slot | Count | Can hold |
|---|---|---|
| Common | 4 | Common |
| Uncommon | 3 | Uncommon |
| Reverse holo slot 1 | 1 | Reverse Holo, **ACE SPEC Rare** |
| Reverse holo slot 2 | 1 | Reverse Holo, Illustration Rare, Special Illustration Rare, Hyper Rare |
| Rare slot | 1 | Rare, Double Rare, Ultra Rare |
| Basic Energy | 1 | Basic Energy card |
| Code card | 1 | Pokémon TCG Live code card |

**Confidence:** TCGplayer's opened-pack study places the ACE SPEC Rare in "the
first Reverse Holo slot". Bulbapedia's table agrees. The Basic Energy and code
card come from era-wide sources only.

**Exception:** this is the first set in the era with the ACE SPEC Rare in
reverse holo slot 1.

## Pack order

| Position | Slot |
|---|---|
| 1–4 | Common |
| 5–7 | Uncommon |
| 8 | Reverse holo slot 1 (ACE SPEC Rare) |
| 9 | Reverse holo slot 2 (Illustration Rare, Special Illustration Rare, Hyper Rare) |
| 10 | Rare slot (Double Rare, Ultra Rare) |
| 11 | Basic Energy |

**Confidence: industry news report before release** (PokeBeach, era-wide,
about the Scarlet & Violet set). No source in this research shows an opened
pack of this set card by card.

- **Double Rare and Ultra Rare:** card 10, the third card from the end. It is
  one of the last three cards.
- **Illustration Rare, Special Illustration Rare, and Hyper Rare:** card 9,
  the fourth card from the end. It is not one of the last three cards.
- **ACE SPEC Rare:** card 8, the fifth card from the end. It is not one of
  the last three cards.
- If the rip screen hides the code card, card 9 is the third card from the
  end, and card 8 is the fourth.
- A single pack can hold an ACE SPEC Rare, a Special Illustration Rare, and an
  Ultra Rare at the same time (TCGplayer).
- **Era conflicts** (Hyper Rare slot, last card): see the era file.

## Special subsets and mechanics

### ACE SPEC cards

- ACE SPEC cards return in this set. A deck can hold only one ACE SPEC card
  of any kind (Bulbapedia).
- The set has seven ACE SPEC Trainer and Special Energy cards, for example
  Prime Catcher and Maximum Belt (TCGplayer, Bulbapedia).
- The cards have a magenta or pink design and their own rarity, ACE SPEC Rare,
  with a pink star symbol (TCGplayer, Bulbapedia).
- They are part of the main set numbering, not secret rares (Bulbapedia set
  list).

### Rate change

The Special Illustration Rare rate fell to 1.17% (Paradox Rift: 2.11%). The
Hyper Rare rate fell to 0.72% (Paradox Rift: 1.22%) (TCGplayer).

### God packs

No source in this research reports a god pack or a demi-god pack for this
set.
