# Fossil (1999)

Set data for Fossil. The era template is in
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md). This file
records the Fossil values and the differences from the template.

## Release

- **English release date:** October 10, 1999. PSA says WotC first
  planned a release "around January 2000".
- **Set symbol:** yes (Bulbapedia). Abbreviation: Unknown. ThePriceDex
  uses the database ID `base3`.
- **Card count:** 62. No secret rares.
- **Rarity split:** 15 holo rares, 15 non-holo rares, 15 uncommons,
  17 commons (PSA).
- **1st Edition vs. Unlimited:** both exist. Unlimited holos with a
  ©1999 date "can also be found with Cosmos holofoil pattern instead
  of the usual Galaxy holofoil" (Bulbapedia). No source shows a
  pull-rate difference.

## Pack structure

- 11 cards per pack.
- 1 rare slot, 3 uncommons, 7 commons (PSA, ThePriceDex).
- Energy card: Unknown. ThePriceDex lists no energy row for Fossil.

## Pack order

Fossil follows the era pack order. See
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md#pack-order).

- **Claim A** ([CardCollector](https://cardcollector.co.uk/pokemon-card-trick-pack-opening/)):
  "3" for Fossil. The rare is card 8 of 11, the fourth card from the
  end (our derivation). **Not** one of the last three. Confidence: low.
- **Claim B** ([NinePocket](https://www.ninepocket.net/guides/pokemon-pack-trick)):
  no reliable order for this era. Confidence: low.
- **Energy card position:** Unknown.

## Special subsets and print errors

- **Holofoil:** "Fossil was the final expansion to use the Starlight
  Holofoil" (Bulbapedia).
- **Zapdos holo:** the card "has a space for the evolution box punched
  out", but Zapdos is a Basic Pokémon (PSA).
- **Australian print:** Unlimited packaging uses red "Pokémon"
  lettering (Bulbapedia).
