# Neo Destiny (2002)

Set data for Neo Destiny. The era template is in
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md). This file
records the Neo Destiny values and the differences from the template.

## Release

- **English release date:** February 28, 2002.
- **Set symbol:** yes (Bulbapedia). Abbreviation: Unknown. ThePriceDex
  uses the database ID `neo4`.
- **Card count:** 105 in the main set, plus 8 Shining Pokémon secret
  rares. Total 113. The Shining cards are Celebi, Charizard, Kabutops,
  Mewtwo, Noctowl, Raichu, Steelix, and Tyranitar.
- **1st Edition vs. Unlimited:** both exist. "Neo Destiny was the final
  English expansion that have the 1st Edition symbol" (Bulbapedia).
  The error print run (see below) appears only in Unlimited boxes in
  the Elite Fourum sample.

## Pack structure

- 11 cards per pack.
- 1 rare slot, 3 uncommons, 7 commons (PSA, ThePriceDex).
- Energy card: Unknown. ThePriceDex lists no energy row.
- **Exception, error print run:** some packs hold a holo and a Shining
  Pokémon. The Shining card fills a common slot, so the pack has
  6 commons (Elite Fourum).

## Pack order

Neo Destiny follows the era pack order. See
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md#pack-order).

- **Claim A** ([CardCollector](https://cardcollector.co.uk/pokemon-card-trick-pack-opening/)):
  "3" for Neo Destiny. The rare is card 8 of 11, the fourth card from
  the end (our derivation). **Not** one of the last three.
  Confidence: low.
- **Claim B** ([NinePocket](https://www.ninepocket.net/guides/pokemon-pack-trick)):
  no reliable order for this era. Confidence: low.
- **Shining Pokémon position, normal packs:** Unknown. No source says
  which slot a Shining card uses in a normal pack.
- **Shining Pokémon position, error packs:** a common slot (Elite
  Fourum). The position of that common slot in the pack is Unknown. So
  an error pack can have a hit outside the rare position.

The Elite Fourum guide says: "For the 'non-error' print runs, the
Shining Pokémon set a new record for 'rarest card so far'." The guide
saw no error pack with a rare and a Shining card, and no pack with two
Shining cards.

## Special subsets and mechanics

- **Light Pokémon:** "Light Pokémon cards have a white and gold artwork
  window, Evolution box and Pokédex box" (Bulbapedia).
- **Shining Pokémon:** "Shining Pokémon now have Non Holofoil
  background, while the Pokémon were given a glossy metallic look"
  (Bulbapedia). PSA describes foil on "only the Pokémon (and not the
  background)".
- **Commons sheet:** the guide reports a 110-card commons sheet
  (10 × 11), the first one seen in the era.
- **Print errors:** a wrong "c" in "Exeggutor" on card 33, and "hust"
  for "just" in the Shining Tyranitar flavor text (PSA).
