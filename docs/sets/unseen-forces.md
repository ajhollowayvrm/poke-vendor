# EX Unseen Forces (2005)

Set-specific data for EX Unseen Forces, the tenth set of the EX Series.
The shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

EX Unseen Forces adds a 28-card Unown subset, numbered outside the
main set (Bulbapedia).

## Pack structure

Follows the era's pack template ([eras/ex.md](eras/ex.md#pack-contents)):
9 cards per pack, 36 packs per box (Bulbapedia). **Confidence:
community estimate** for the common and uncommon split; the era's two
conflicting source counts (5/2 vs. 4/3) both remain open for this set.

- **Reverse Holofoil.** Bulbapedia: this set's Reverse Holofoil pattern
  is a 3D Poké Ball pattern.
- **Unown cards sit in the reverse holo slot or a special product,
  not a normal pack slot.** No fetched source states the pack odds for
  an Unown card in a standard booster pack. See Special subsets and
  mechanics below.

## Rarities and hit odds

**Confidence: unknown** for the rare-slot rows. No box-count study
(Elite Fourum's "Guide to early EX Series pull rates," or any other

the Elite Fourum thread does not cover this set, and a dedicated

(16.24–16.33 grams for four packs from one box), not pull rates.

results) states that a collector who opened 20 unweighed packs pulled

confirmation.

## Special subsets and mechanics

- **Unown subset.** 28 cards, one per Unown form (the 26 letters A–Z,
  plus "!" and "?"), classified as Rare Holo and numbered outside the
  main 115-card set plus 2 Secret Rares (Bulbapedia). No fetched source
  states whether these pull from a normal pack slot or only from a
  separate product. See Open topics.
- **Rare Holo ☆.** Entei ☆, Raikou ☆, Suicune ☆
  ([eras/ex.md](eras/ex.md#sets-that-break-the-template)).
- **Secret Rares.** Rocket's Persian ex and Celebi ex, at 116–117/115
  ([eras/ex.md](eras/ex.md#sets-that-break-the-template)).
- **God packs:** no source found. Confidence: unknown.
