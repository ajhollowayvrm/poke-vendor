# 30th Celebration (2026)

Set data for 30th Celebration, a special expansion of the Mega Evolution
Series for the 30th anniversary of the Pokémon TCG. See
[../13-sets.md](../13-sets.md) for the approach. See
[eras/mega-evolution.md](eras/mega-evolution.md) for the era template.
**This set breaks the era template.** The closest model is
[celebrations.md](celebrations.md), the 25th anniversary set.

Research date: 2026-11-05. The set released 7 weeks before this date.
Every pull rate here comes from community and retailer counts. The
Pokémon Company does not publish pull rates.

## Release

- **English release**: 2026-09-16 (Bulbapedia, TCGdex, TCGplayer). This
  is the first set with one worldwide release date (Bulbapedia,
  NinePocket).
- **Set code**: 30C (TCGdex abbreviation). Bulbapedia gives no set number.
- **TCGdex**: two sets. `30th` (30th Celebration, 128 official + 30
  secret = 158 cards) and `30th-c` (30th Classic Collection, 30 cards).
  This is the same shape as Celebrations (`cel25` and `cel25cc`).
- **TCGplayer groups**: `24722` (main set and sealed product) and `24837`
  (Classic Collection).
- **Card count** (Bulbapedia raw set list, English, 2026-11-05): 191
  cards.

| Part | Numbers | Bulbapedia rarity | Cards |
|---|---|---|---|
| Main set | 001–128 | Common | 68 |
| Main set | 023–052 | Pikachu rare (no rarity symbol; numbered 01/30 to 30/30 too) | 30 |
| Main set | 001–128 | Rare | 18 |
| Main set | 001–128 | Double Rare | 12 |
| Secret | 129–146 | Illustration Rare | 18 |
| Secret | 147–156 | Special Illustration Rare | 10 |
| Secret | 157–158 | Futuristic Rare (Mewtwo ex, Mew ex) | 2 |
| Secret | R/RGB, G/RGB, B/RGB | RGB Rare (Mew) | 3 |
| Classic Collection | original numbers, for example 4/102 | the original rarity of each card | 30 |

- The set has no Uncommon cards and no reverse holos. Every card is
  foil, including the Basic Energy (official expansion page, Bulbapedia).
- TCGdex has 188 cards. It does not have the 3 RGB Rare Mew cards.
  TCGplayer has them (group `24722`, rarity "RGB Rare").
- NinePocket quotes a reported total of 199: 128 main, 33 secret, 30
  Classic Collection, and 8 Basic Energy. This agrees with Bulbapedia
  when the 8 Basic Energy cards are removed.
- The English set merges the Japanese 30th Celebration (M6a, 103 main
  cards) with the Japanese Premium Deck Set Espeon & Umbreon
  (Bulbapedia).

## Pack structure

- Pokémon Center listings: five foil cards, one foil Basic Energy, and
  one Pokémon TCG Live code card (quoted by NinePocket). Bill's Archive
  and CardCodex give the same contents. **Confidence: official
  (retailer listing), with three community sources in agreement.**
- Bulbapedia: "Each booster pack of 30th Celebration contains 5 cards,
  one of which is one of the 30 Pikachu rare cards, plus an additional
  Basic Energy card." Bulbapedia does not mention the code card.
- Official expansion page: "every card in a 30th Celebration booster
  pack is foil and ... every pack includes a Pikachu rare card".
- The era file says that the pack holds "5 cards, 1 Basic Energy, and
  1 code card". This research confirms it.
- Japanese M6a packs hold 6 cards: the same 5 cards plus the Basic
  Energy (Samurai Sword Tokyo). This file is for the English pack only.

Slot structure. Source: a count of 4,063 packs from opening streams, by
Discord user Tommy13 (Wargamer, 2026-09-17; Bill's Archive). **Confidence:
community sample, one source for the slots.**

| Slot | Count | What the slot can hold |
|---|---|---|
| Common | 2 | Common (two pools of 23 cards) |
| Third card | 1 | Common (a pool of 22 cards), or an Illustration Rare, or a Classic Collection card |
| Rare slot | 1 | Rare (a holo legendary), or a Double Rare, Special Illustration Rare, Futuristic Rare, or RGB Rare |
| Pikachu | 1 | Pikachu rare (one of 30) |
| Basic Energy | 1 | Foil Basic Energy (one of 8) |
| Code card | 1 | Pokémon TCG Live code card |

- Wargamer: "Slot 3 - third common, or hits. ... Illustration Rare and
  Classic Classic Collection Rare cards can appear in Slot 3." and "Slot
  4 - rare slots. Ordinarily this slot is filled by rare Legendaries,
  but it can be bumped by Double Rares, Special Illustration Rares,
  Futuristic Rares, and RGB rares."
- Bill's Archive: "Because the Illustration Rare and Classic Collection
  share one slot while the ex tiers share another, a pack can hold two
  hits at once." A Special Illustration Rare and a Futuristic Rare
  cannot come in the same pack.
- The three common pools (23 + 23 + 22 = 68) are fixed groups of cards.
  No source in this research lists which card is in which pool.
- When the third card is a hit, the commons move up one slot (Wargamer).
  The pack then holds 2 commons, not 3.

## Pack order

**Confidence: community sample** for positions 1 to 5 (the 4,063-pack
count records "every card in every slot"). **Unknown** for the Basic
Energy and the code card.

| Position | Card | Hit? |
|---|---|---|
| 1 | Common | No (price can make it a hit) |
| 2 | Common | No (price can make it a hit) |
| 3 | Common, or an Illustration Rare or Classic Collection card | IR and Classic Collection are hits |
| 4 | Rare slot | Yes (Rare or higher) |
| 5 | Pikachu rare | Yes by the rarity rule (see below) |
| 6 | Basic Energy (assumed) | No |
| 7 | Code card (assumed) | No |

- Positions 6 and 7 follow the era template, where the Energy and the
  code card are the last two cards. No source describes them for this
  set.
- **The rare slot is not at the back of the cards.** The Pikachu rare
  comes after it. This differs from every other Mega Evolution set.
- Where the hit sits: the rare slot is position 4 of 7, and the third
  card is position 3 of 7. **Neither is one of the last three cards.**
  If the rip screen skips the code card (6 cards), the rare slot is one
  of the last three cards, but the third card is not.
- The Pikachu rare has the rarity "Pikachu rare". The rarity rule in
  [../18-ripping.md](../18-ripping.md#what-counts-as-a-hit) counts
  "rare or higher" as a hit. This file treats the Pikachu rare as a
  hit, so every pack holds at least one hit. Its average price is about
  $2 (Bill's Archive), so the price rule also makes it a hit.

## Rarities and hit odds

Main source: TCGplayer Authentication Center, "more than 3,000" packs,
with 95% ranges (reported by Polkastarter, CardCodex, and The Card Shop
Finder from PokeBeach, 2026-09-23). This file did not read the TCGplayer
study directly.

| Rarity | Odds per pack | Confidence |
|---|---|---|
| Common | 2 or 3 per pack | Community sample (slot structure) |
| Pikachu rare | Every pack | Official |
| Rare | 69.29% (the rest of the rare slot) | Arithmetic on the figures below |
| Double Rare | 1 in 4 (25.0%) | Community sample (4,063 packs). See the conflict below |
| Illustration Rare | 1 in 5 (19.72% ±1.37%) | Retailer study (3,000+ packs) |
| Classic Collection | 1 in 10 (10.15% ±1.04%) | Retailer study (3,000+ packs) |
| Special Illustration Rare | 1 in 21 (4.88% ±0.74%) | Retailer study (3,000+ packs) |
| Futuristic Rare | 1 in 120 (0.83% ±0.31%) | Retailer study (3,000+ packs), low count |
| RGB Rare (Mew) | Unknown. 1 seen in 4,063 packs | Community sample, 1 pull |

### Four community counts

Bill's Archive compares four counts by different people. Sources, in
column order: the 4,063-pack stream count (Tommy13, via Wargamer), the
running tally on CardPrice, TCG Talk's verified openings, and DigitalTQ.

| Rarity | 4,063 packs | ~800 packs | 652 packs | 420 packs |
|---|---|---|---|---|
| Double Rare | 1 in 4.0 | 1 in 4.4 | 1 in 4.6 | 1 in 3.6 |
| Illustration Rare | 1 in 5.2 | 1 in 5.6 | 1 in 5.4 | 1 in 5.0 |
| Classic Collection | 1 in 9.8 | 1 in 10.5 | 1 in 10.2 | 1 in 9.5 |
| Special Illustration Rare | 1 in 18 | 1 in 19.8 | 1 in 18.1 | 1 in 19.1 |
| Futuristic Rare | 1 in 99 | 1 in 100 | 1 in 82 (8 pulls) | 1 in 105 (4 pulls) |

- Bill's Archive: "The 420-pack count classes the Double Rares more
  broadly, which is why its figure runs high."
- Bill's Archive: "Stream openings can over-represent exciting packs if
  the dull ones are edited out". The TCGplayer study has no such bias,
  so this file uses the TCGplayer figures where it can.
- TCG Talk (652 packs): about 43% of packs hold nothing better than the
  Pikachu rare.

### Conflicting figures

- **Double Rare**: TCGplayer gives 21.02% ±1.21% in the secondary
  reports. Pitch Black's 4,000-pack study (Obsidia) gives exactly the
  same figure and range. This is probably a copy error in the reports.
  The four community counts give 1 in 3.6 to 1 in 4.6 (22% to 28%).
  Default: 25.0%, from the largest community count.
- **Special Illustration Rare**: 1 in 21 (TCGplayer) against 1 in 18 to
  1 in 20 (community counts). Default: TCGplayer.
- **Futuristic Rare**: 1 in 120 (TCGplayer) against 1 in 82 to 1 in 105
  (community counts). Default: TCGplayer.
- **RGB Rare**: TCGplayer found none in 3,000+ packs. The 4,063-pack
  count found 1. Tommy13 puts the true rate anywhere from 1 in 718 to
  1 in 23,016. CardCodex reports a count of "roughly 1 in 3,200 across
  6,500 packs" with no named source. Bill's Archive: "The
  one-in-20,000 figure that circulated in the first week has no
  published source."
- **TCG Watchtower** lists an IR rate near 11% and an SIR rate near 1.2%
  per pack. These match the main Mega Evolution sets, not this set.
  Treat them as wrong.

## Special subsets and mechanics

- **Pikachu rare**: 30 Pikachu cards by 30 artists, numbered 023–052
  and 01/30 to 30/30. One in every pack. Each has its own holofoil
  pattern. No source gives the odds of each Pikachu. Bill's Archive
  assumes equal odds.
- **Classic Collection**: 30 reprints of older cards, with a gold border
  and a 30th anniversary stamp. They keep their original numbers. They
  come in ordinary packs at about 1 in 10, in the third card. The
  official expansion page: "As you open booster packs looking for
  brand-new cards, you'll have a chance to encounter some of the most
  iconic Pokémon TCG cards of all time." Before release, many sources
  expected them only in the Classic Collection Pack.
- **Classic Collection Pack**: a separate 3-card pack. Every card is a
  Classic Collection card (TCG Talk, from openings). It comes only in the
  Ultra-Premium Collections, and TCGplayer sells it as a loose product
  (product 704192). It is not a 30th Celebration booster pack, and the
  slot map does not cover it.
- **Futuristic Rare**: a new rarity, by the artist YOSHIROTTEN. Two
  cards: Mewtwo ex 157/128 and Mew ex 158/128.
- **RGB Rare**: three Mew cards (R/RGB, G/RGB, B/RGB) by YOSHIROTTEN.
  They are not in the official card gallery or the checklist booklet.
  They came out of packs from 2026-09-12 (NinePocket).
- **God packs**: no source reports a god pack for English packs.
- **Japanese boxes** have fixed box-level rules: a 20-pack M6a box held
  2 Classic Collection cards and 1 Special Art Rare (PokeBeach via Samurai
  Sword Tokyo; Bill's Archive, 57 boxes). English packs are independent
  draws (Bill's Archive).

## Slot map

How the game builds one pack from the card list. Each row is one
outcome of one slot. The game picks one outcome for each card in the
slot, then picks one card at random from the cards that match the row.

- **Slot** and **Count** come from the pack structure above.
- **Rarity list entry** links the outcome to the stop rule.
- **TCGdex rarity** and **Variant** match the card list exactly.
- **Cards** limits the matching cards: `All`, `Nos. a–b`, `Not nos. a–b`,
  `Part: <card list table>`, or `Category: <category>`.
- **Odds in slot** is the chance of the outcome for one card in the
  slot. `Rest` is the remainder. `—` means no source gives the odds.
- A variant that no row uses does not come from booster packs.

Confidence: the slots come from one community count (4,063 packs). The
odds come from the TCGplayer study, except Double Rare (see Conflicting
figures). The two Common slots use all 68 commons, because no source
lists the three common pools. TCGdex has no RGB Rare cards, so the map
has no row for them. TCGdex gives the Classic Collection cards the
rarity "None".

## Open topics

- **Pack order of the Basic Energy and the code card**: Searched
  2026-11-05: no source found. This file assumes the era template
  (the last two cards).
- **Common pools**: the 4,063-pack count found three fixed pools
  (23, 23, and 22 cards). Searched 2026-11-05: no source lists the cards
  in each pool. The slot map uses all 68 commons in each Common slot.
- **Double Rare odds**: the TCGplayer figure (21.02%) matches Pitch
  Black's figure exactly. Default: 25.0% from the 4,063-pack count.
  Read the TCGplayer study directly to settle this.
- **RGB Rare**: no reliable odds, and TCGdex does not have the 3 cards.
  The slot map has no row for them, so the game never gives one.
- **Pikachu rare odds per card**: no source. The game uses equal odds.
- **Classic Collection odds per card**: no source. TCG Talk saw no reprint
  more than 4 times in 652 packs. The game uses equal odds.
- **Slot map:** when the third card is a hit, the real pack holds
  2 commons. The slot map gives the same result: 2 Common slots and a
  third card that is a common only when it is not a hit.
- **Rarity list order:** Classic Collection (10.15%) is more common than
  Special Illustration Rare (4.88%), so it comes first. The Pikachu rare
  comes in every pack, so its default stop is No.
- **Classic Collection card numbers**: TCGdex numbers the subset
  001–030. TCGplayer uses the original numbers, for example 4/102.
  Three cards share the number 106. `tools/cardlist/product-ids.json`
  maps each TCGdex number to its TCGplayer product, and the card list,
  the join, and the export match these cards by that product. TCGplayer
  lists every Classic Collection card as Holofoil only.
- **Single packs**: NinePocket says that single packs are not sold at
  retail. TCGplayer lists a loose booster pack. The game can sell a
  loose pack at the TCGplayer price.
