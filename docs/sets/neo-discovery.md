# Neo Discovery (2001)

Set data for Neo Discovery. The era template is in
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md). This file
records the Neo Discovery values and the differences from the template.

## Release

- **English release date:** June 1, 2001.
- **Set symbol:** yes (Bulbapedia). Abbreviation: Unknown. ThePriceDex
  uses the database ID `neo2`.
- **Card count:** 75. No secret rares.
- **1st Edition vs. Unlimited:** both exist. "The Neo Discovery set is
  released in English, German, French, and Italian, in both 1st and
  unlimited edition" (Bulbapedia). PSA quotes an expert: "fewer Neo
  Discovery cards were produced than Neo Genesis".

## Pack structure

- 11 cards per pack.
- 1 rare slot, 3 uncommons, 7 commons (PSA, ThePriceDex).
- Energy card: Unknown. ThePriceDex lists no energy row.

## Pack order

Neo Discovery follows the era pack order. See
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md#pack-order).

- **Claim A** ([CardCollector](https://cardcollector.co.uk/pokemon-card-trick-pack-opening/)):
  "3" for Neo Discovery. The rare is card 8 of 11, the fourth card from
  the end (our derivation). **Not** one of the last three.
  Confidence: low.
- **Claim B** ([NinePocket](https://www.ninepocket.net/guides/pokemon-pack-trick)):
  no reliable order for this era. Confidence: low.
- **Belgian print:** this print used "striped collation". Cards that
  sat above each other on the sheet come out in sequence in a pack
  (Elite Fourum). The English print used sequential collation. Neither
  fact gives the rare position.

## Special subsets and mechanics

- **Unown:** the set has several Unown cards, one per letter (A, D, E,
  F, I, M, N, O, U) (Bulbapedia). PSA places them among the non-holo
  commons and uncommons.
- **Two print runs:** the Elite Fourum guide found a sequential
  collation print and a Belgian striped collation print. They use
  different sheet layouts.
