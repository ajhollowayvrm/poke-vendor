# Battle Styles (2021)

Set data for Battle Styles. See [../13-sets.md](../13-sets.md) for the
approach. See [eras/sword-shield.md](eras/sword-shield.md) for the era
template and the evidence behind the pack order.

## Release

- English release: March 19, 2021.
- Set code: SWSH5. Abbreviation: BST. TCGplayer set code: SWSH05.
- Cards: 183 total. 163 in the main numbering, plus 20 secret rares.

## Pack structure

- 10 game cards, 1 basic Energy card, and 1 code card for the Pokémon Trading
  Card Game Online.
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo,
  1 rare or higher.
- No subset in this set.

## Pack order

**Confidence: community guide** (era template, no set-specific source).

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo |
| 7 | Rare slot |
| 8 | Basic Energy |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- With the community pack trick, the rare is last.
- Which end faces the wrapper front: Unknown.

- TCGplayer says the set "brings back alternate-art Pokémon cards for the
  first time since the Sun & Moon Series."
