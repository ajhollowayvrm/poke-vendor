# Brilliant Stars (2022)

Set data for Brilliant Stars. See [../13-sets.md](../13-sets.md) for the
approach. See [eras/sword-shield.md](eras/sword-shield.md) for the era
template and the evidence behind the pack order.

## Release

- English release: February 25, 2022.
- Set code: SWSH9. Abbreviation: BRS. TCGplayer set code: SWSH09.
- Cards: 216 total. 172 in the main numbering, plus 14 secret rares, plus 30
  Trainer Gallery cards (TG01–TG30).

## Pack structure

- Bulbapedia: "Each Brilliant Stars booster pack contains ten cards from the
  expansion, a code card for use with the Pokémon Trading Card Game Live, and
  either a basic Energy card (featuring a new design) or a VSTAR marker card."
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo
  slot, 1 rare slot.
- A Trainer Gallery card replaces the reverse holo (DigitalTQ; TCGplayer
  confirms the slot for the later Trainer Gallery sets).

## Pack order

**Confidence: community guide.** NinePocket lists Brilliant Stars and its
Trainer Gallery under the Sun & Moon to Sword & Shield method.

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo slot (can be a Trainer Gallery card) |
| 7 | Rare slot |
| 8 | Basic Energy or VSTAR marker |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- A Trainer Gallery hit sits next to the rare slot, near the middle.
- With the community pack trick, the rare is last and the reverse holo slot
  is second-to-last.
- Which end faces the wrapper front: Unknown.

## Special subsets or mechanics

- First set with the Trainer Gallery. The subset uses the reverse holo slot.
- First set with Pokémon VSTAR. A VSTAR marker card can replace the Energy
  card.
