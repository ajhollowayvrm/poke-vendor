# EX Dragon Frontiers (2006)

Set-specific data for EX Dragon Frontiers, the fifteenth set of the EX
Series. The shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

Bulbapedia describes the set as centered on "an island far away where
natural Delta Species Pokémon thrive," with δ Delta Species "present on
virtually all Pokémon cards" in the set.

## Pack structure

Follows the era's pack template ([eras/ex.md](eras/ex.md#pack-contents)):
9 cards per pack, 36 packs per box (Bulbapedia and Elite Fourum both
confirm 36 packs per box for this set). **Confidence: community
estimate** for the common and uncommon split; the era's two
conflicting source counts (5/2 vs. 4/3) both remain open for this
set.

## Rarities and hit odds

The Elite Fourum "Guide to early EX Series pull rates" thread gives a
box-count breakdown for this set, from a poster named zorloth
responding to a direct question. **Confidence: community estimate**;
the thread's author states the guide's figures come from "extensive
research, second hand reports, and data" the author personally
collected.

| Rarity | Per 36-pack box | Per pack | Confidence |
|---|---|---|---|
| Common | 180 (6 of each common) | Every pack (5 per pack) | Community estimate |
| Uncommon | 72 (2.3 of each uncommon) | Every pack (2 per pack) | Community estimate |
| Rare | 24 (1.5 of each rare) | ~1 in 1.5 packs | Community estimate |
| Rare Holo | 8.5 (0.7 of each Rare Holo) | ~1 in 4.2 packs | Community estimate |
| Rare Holo ex | 3 (0.3 of each ex) | ~1 in 12 packs | Community estimate |
| Rare Holo ☆ | 0.5 (0.3 of each Gold Star) | ~1 in 72 packs | Community estimate |
| Secret Rare | Unknown | Unknown | Unknown |

This set has no Secret Rare in [eras/ex.md](eras/ex.md#sets-that-break-the-template),
so the Secret Rare row above is Unknown by default, not a gap in the
box-count breakdown.

**Default for the simulation:** treat the rare slot as one card per
pack, drawn from Rare, Rare Holo, Rare Holo ex, or Rare Holo ☆, using
the box-count figures above.

## Special subsets and mechanics

- **δ Delta Species.** Bulbapedia describes δ as present on "virtually
  all Pokémon cards" in this set. Bulbapedia's EX Crystal Guardians
  page, for the set released before this one, calls Crystal Guardians
  "the last expansion" for δ Delta Species — a claim that conflicts
  with this set
  ([eras/ex.md](eras/ex.md#conflicts-in-the-template)). This file
  records both and does not pick a position.
- **Rare Holo ☆.** Charizard ☆ δ and Mew ☆ δ
  ([eras/ex.md](eras/ex.md#sets-that-break-the-template)).
- **God packs:** no source found. Confidence: unknown.
