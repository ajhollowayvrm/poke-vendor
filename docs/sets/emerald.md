# EX Emerald (2005)

Set-specific data for EX Emerald, the ninth set of the EX Series. The
shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

EX Emerald is the only EX-era set with no Rare Holo ☆ and no Secret
Rare Pokémon, and it replaces the reverse holo slot with a Holofoil
Basic Energy card in every third pack (Bulbapedia).

## Pack structure

Follows the era's pack template ([eras/ex.md](eras/ex.md#pack-contents)):
9 cards per pack, 36 packs per box. **Confidence: community estimate**
for the common and uncommon split; the era's two conflicting source
counts (5/2 vs. 4/3) both remain open for this set.

- **Exception: the reverse holo slot.** Bulbapedia states EX Emerald
  "introduced Holofoil Basic Energy cards, which replaced the Reverse
  Holofoil in every third pack of a booster box." So 1 pack in 3 carries
  a Holofoil Basic Energy card in the slot the era template otherwise
  gives to a reverse holo. Confidence: empirical study (Bulbapedia
  states this as a specific, countable pack behavior, not a general
  estimate).
- No Rare Holo ☆ exists in this set ([eras/ex.md](eras/ex.md#odds-by-set)
  gives a dash in the Gold Star column for EX Emerald).

## Special subsets and mechanics

- **Holofoil Basic Energy.** Replaces the reverse holo in every third
  pack (Bulbapedia). No other EX-era set file describes this mechanic.
- **No Rare Holo ☆.** The set has one Secret Rare: Farfetch'd, a
  Colorless Pokémon, at 107/106 (Bulbapedia set list).
- **God packs:** no source found. Confidence: unknown.
