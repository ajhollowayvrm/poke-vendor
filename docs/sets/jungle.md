# Jungle (1999)

Set data for Jungle. The era template is in
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md). This file
records the Jungle values and the differences from the template.

## Release

- **English release date:** June 16, 1999. PSA says WotC first planned
  an August 1999 release. WotC moved the date forward when it learned
  that Topps was releasing Pokémon cards earlier that summer.
- **Set symbol:** yes (Bulbapedia). Abbreviation: Unknown. ThePriceDex
  uses the database ID `base2`.
- **Card count:** 64. No secret rares.
- **Rarity split:** 16 holo rares, 16 non-holo rares, 16 uncommons,
  16 commons (PSA). WotC added non-holo copies of the 16 holos to the
  English set. The Japanese set has 48 cards.
- **1st Edition vs. Unlimited:** both exist. No source shows a
  pull-rate difference between them.

## Pack structure

- 11 cards per pack.
- 1 rare slot, 3 uncommons, 7 commons (PSA, ThePriceDex).
- Energy card: Unknown. ThePriceDex lists no energy row for Jungle.

## Pack order

Jungle follows the era pack order. See
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md#pack-order).

- **Claim A** ([CardCollector](https://cardcollector.co.uk/pokemon-card-trick-pack-opening/)):
  "3" for Jungle. The rare is card 8 of 11, the fourth card from the
  end (our derivation). **Not** one of the last three. Confidence: low.
- **Claim B** ([NinePocket](https://www.ninepocket.net/guides/pokemon-pack-trick)):
  no reliable order for this era. Confidence: low.
- **Energy card position:** Unknown.

## Special subsets and print errors

- **Error Pikachu promo (1st Edition):** PSA says the Ivy Pikachu Black
  Star promo went into some booster packs by accident, about 1 per 10
  boxes. Confidence: community estimate.
- **Error packs:** the Elite Fourum guide reports a streamer (Murkd_)
  who found "three Jungle packs containing ONLY promo Pikachus in the
  uncommon slot". Confidence: single observation.
- **No-symbol holos (Unlimited):** "All the English Holofoil Rares in
  the unlimited edition Jungle set were also accidentally printed as
  error cards without set symbol" (Bulbapedia).
- **Belgian print:** the Elite Fourum guide lists a Belgian variant.
- **Australian print:** the Unlimited packaging uses red "Pokémon"
  lettering (Bulbapedia).
