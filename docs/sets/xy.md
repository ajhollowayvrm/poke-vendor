# XY (2014)

Set-specific data for XY, the first set of the XY era. See
[../13-sets.md](../13-sets.md) for what a set file covers. See
[eras/xy.md](eras/xy.md) for the pack template of this era.

## Release

- English release: February 5, 2014 (Bulbapedia, Limitless TCG).
- Code: XY. Set symbol: a stylized XY mark (Bulbapedia image).
- Card count: 146 cards. Secret rares: none found. The Bulbapedia
  expansion list gives 146 with no secret rares.

## Pack structure

This set follows the XY-era template. Confidence: **community wiki and
community estimate**.

- 10 cards per pack, plus 1 code card.
- 1 rare slot, 1 reverse holo, 3 uncommons, 5 commons.
- No separate Energy slot. ThePriceDex lists Energy at "1 in 2.2
  packs" and commons at "4.5 cards per pack". Basic Energy cards come
  in the common slots.

## Pack order

This set follows the XY-era order. No source describes this set
separately. Confidence: **community guide, era-wide**.

1. Positions 1–5: five cards (inferred: commons).
2. Position 6: reverse holo.
3. Position 7: rare slot (the hit).
4. Positions 8–10: three cards (inferred: uncommons).
5. Position 11: code card.

The hit is **not** one of the last three cards. It is card 7 of 10.
The code card back hints at the rare tier (see
[eras/xy.md](eras/xy.md#the-code-card-hint)).

## Rarities and hit odds

Rarities: Common, Uncommon, Rare, Rare Holo, Rare Holo EX
(Bulbapedia). ThePriceDex also lists an Ultra Rare (full art) tier.

| Rarity (rare slot) | Per pack | Per box (36) | Confidence |
|--------------------|----------|--------------|------------|
| Rare (non-holo) | 1 in 1.5 | 23.6 | Community estimate |
| Rare Holo | 1 in 4.3 | 8.4 | Community estimate |
| Rare Holo EX | 1 in 12 | 3 | Community estimate |
| Ultra Rare (full art) | 1 in 36 | 1 | Community estimate |
| Secret Rare | None in set | — | Community wiki |
| Holo rare or better (derived) | about 1 in 2.9 | about 12.4 | Derived from the rows above |

All per-pack figures come from ThePriceDex.

Reverse holo slot (ThePriceDex, **community estimate**): Reverse Rare
Holo "1 in 8.6 packs", Reverse Rare "1 in 4.7 packs", Reverse
Uncommon "1 in 2.9 packs", Reverse Common "1 in 3.1 packs".

Flipside Gaming says that early in the era, pull rates "matched prior
sets". It gives no XY number. Confidence: **community estimate**.

## Special subsets and mechanics

- M Pokémon-EX (Mega Evolution) cards start in this set (Bulbapedia).
- The Fairy type starts in the TCG with this set (Bulbapedia).
- Bulbapedia: "This is the first pack to change the TCG's requiring
  age from 10+ to 6+."
