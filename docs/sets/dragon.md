# EX Dragon (2003)

Set-specific data for EX Dragon, the third set of the EX Series. The
shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

EX Dragon is the first set in the era with a Secret Rare. It still has
no Rare Holo ☆ (see
[eras/ex.md](eras/ex.md#sets-that-break-the-template)).

Not confirmed. If the era's one secondary claim holds, the hit sits at
position 8 or 9 of 9, inside the last three cards. No source confirms
this for EX Dragon specifically. A Secret Rare, when pulled, occupies
the rare slot in place of a Rare, Rare Holo, or Rare Holo ex.

This is the only EX-era set in the era's odds table with a Rare Holo ex

## Special subsets and mechanics

- **First Secret Rare in the era.** A 3-card Charmander evolution line
  at 98–100/97, printed past the set's 97-card total (Bulbapedia).
- **Pokémon-ex continues.** Bulbapedia describes Pokémon-ex as a
  "significant gameplay innovation" with new deck-building strategies,
  continuing from EX Ruby & Sapphire.
- **No Rare Holo ☆.** Confirmed by
  [eras/ex.md](eras/ex.md#sets-that-break-the-template). Rare Holo ☆
  starts with EX Team Rocket Returns.
- **God packs:** no source found. Confidence: unknown.

## Rarity list

The stop rule menu on the rip screen shows this list (see
[../18-ripping.md](../18-ripping.md#the-stop-rule)). The list goes from
the most common entry to the rarest entry. Rare Holo ex (6 per box) is
more common than Rare Holo (5 per box) in this set's odds data, so this
list places Rare Holo ex before Rare Holo, ahead of its usual place in
the era's rarity system order.

  (21+17+13+12+9+3=75) do not sum to the stated total of 100 cards.
  Searched 2026-09-12: no source resolved the gap. A follow-up pass
  should read Bulbapedia's card list table directly, not a summarized
  extract.
- **Common/uncommon per-pack split.** Not confirmed for this specific
  set. Searched 2026-09-12: no source found; see the general
  Common/uncommon split conflict in

- **Set code.** Not confirmed in a fetched source.
- **Pack order and hit position.** Searched 2026-09-12: no source
  found beyond the one low-confidence secondary claim in
  [eras/ex.md](eras/ex.md#pack-order).
- **Theme Deck names.** Searched 2026-09-12: no source found for this
  set specifically.
- **Rarity list odds:** no source gives odds for Rare beyond "every

  decides its place in the rarity list.

  per box) in this set's box-count data, so this file places Rare Holo
