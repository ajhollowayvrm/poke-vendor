# Sword & Shield (2020)

Set data for Sword & Shield, the first set of the Sword & Shield era. See
[../13-sets.md](../13-sets.md) for the approach. See
[eras/sword-shield.md](eras/sword-shield.md) for the era template and the
evidence behind the pack order.

## Release

- English release: February 7, 2020.
- Set code: SWSH1. Abbreviation: SSH. TCGplayer set code: SWSH01.
- Cards: 216 total. 202 in the main numbering, plus 14 secret rares.

## Pack structure

- 10 game cards, 1 basic Energy card, and 1 code card for the Pokémon Trading
  Card Game Online.
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo,
  1 rare or higher.
- No subset in this set.

## Pack order

**Confidence: community guide** (era template, no set-specific source).

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo |
| 7 | Rare slot |
| 8 | Basic Energy |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards. From the other end, the
  rare is position 6 and the reverse holo and 5 commons follow it.
- With the community pack trick, the rare is last and the reverse holo is
  second-to-last.
- Which end faces the wrapper front: Unknown.
