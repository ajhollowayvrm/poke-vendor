# Base Set 2 (2000)

Set data for Base Set 2. The era template is in
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md). This file
records the Base Set 2 values and the differences from the template.

## Release

- **English release date:** February 24, 2000.
- **Set symbol:** yes (Bulbapedia). Abbreviation: Unknown. ThePriceDex
  uses the database ID `base4`.
- **Card count:** 130. No secret rares.
- **Contents:** "Base Set 2 is composed of reprints of the Base Set and
  Jungle expansions" (Bulbapedia).
- **1st Edition vs. Unlimited:** "The Base Set 2 was only released in
  English, without any 1st edition print run" (Bulbapedia). Only
  Unlimited exists.

## Pack structure

- 11 cards per pack.
- 1 rare slot and 3 uncommons.
- Sources disagree on the other 7 cards:
  - ThePriceDex: 5 commons and 2 energy.
  - PullMarket: 7 commons (a general statement for all WotC packs).
- The Elite Fourum guide confirms a known energy sheet for this set.

## Pack order

Base Set 2 follows the era pack order. See
[eras/wizards-of-the-coast.md](eras/wizards-of-the-coast.md#pack-order).

- **Claim A** ([CardCollector](https://cardcollector.co.uk/pokemon-card-trick-pack-opening/)):
  "3" for Base Set 2. The rare is card 8 of 11, the fourth card from
  the end (our derivation). **Not** one of the last three.
  Confidence: low.
- **Claim B** ([NinePocket](https://www.ninepocket.net/guides/pokemon-pack-trick)):
  no reliable order for this era. Confidence: low.
- **Energy card position:** Unknown. The set may have 2 energy cards
  per pack, so this matters more here than in other sets.

## Special subsets and print notes

- **Holofoil:** "Base Set 2 was the first English expansion to use the
  Cosmos Holofoil" (Bulbapedia).
- **Energy weights:** the Elite Fourum guide says Base Set and Base
  Set 2 show energy differences that follow theme deck contents. Fire
  and Fighting Energy are the least frequent in Base Set packs.
