## Pack structure

- **10 game cards per pack.** Confidence: official rule, via Bulbapedia.
- **Slots:** 5 commons, 1 reverse holo, 1 rare slot, 3 uncommons.
  Confidence: community template for the era. No source covers this set
  by name.
- **1 code card.** Code cards were in all packs from Emerging Powers on.
- **No basic Energy card.**

## Special mechanics

- Noble Victories introduced Restored Pokémon, a new Fossil mechanic.
- The set holds all of Red Collection, the Victini Battle Theme Deck
  cards, and some Psycho Drive and Hail Blizzard cards.
