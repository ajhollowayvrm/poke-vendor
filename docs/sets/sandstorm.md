# EX Sandstorm (2003)

Set-specific data for EX Sandstorm, the second set of the EX Series.
The shared pack template, pack order, and rarity system are in
[eras/ex.md](eras/ex.md). This file records the set data and every
exception. See [../13-sets.md](../13-sets.md) for the general
approach.

EX Ruby & Sapphire and EX Sandstorm are the only two sets in the era
with no Rare Holo ☆ and no Secret Rare (see
[eras/ex.md](eras/ex.md#sets-that-break-the-template)).

## Special subsets and mechanics

- **Link attacks.** Bulbapedia: the set introduced "new link attacks"
  that let a Trainer "combine the power of two Pokémon."
- **First official Prerelease promo.** Bulbapedia describes EX
  Sandstorm as the first expansion with a Prerelease promo card issued
  through Play! Pokémon events.
- **Reverse holo, multiple languages.** Bulbapedia notes the English,
  French, German, and Italian versions carry Reverse Holo versions of
  non-holo Uncommons and Commons, with different code variants at the
  bottom-left of the card.
- **No Rare Holo ☆ and no Secret Rare.** Confirmed by
  [eras/ex.md](eras/ex.md#sets-that-break-the-template).
- **God packs:** no source found. Confidence: unknown.
