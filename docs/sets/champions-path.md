# Champion's Path (2020)

Set data for Champion's Path, a special expansion. See
[../13-sets.md](../13-sets.md) for the approach. See
[eras/sword-shield.md](eras/sword-shield.md) for the era template and the
evidence behind the pack order.

## Release

- English release: September 25, 2020.
- Set code: SWSH3.5 (official website and checklist). Code card sequence code:
  CP. Abbreviation: CPA. TCGplayer set code: CHP.
- Cards: 80 total. 73 in the main numbering, plus 7 secret rares.

## Pack structure

- 10 cards per pack (TCGplayer). Energy card and code card: the era template
  says 1 of each. No set-specific source confirms this.
- Slots: Unknown. The era template gives 5 commons, 3 uncommons, 1 reverse
  holo, 1 rare or higher.
- The set list has no plain Rare cards. Thus the rare slot is Rare Holo or
  higher (derived from the Bulbapedia set list).

## Pack order

**Confidence: community guide, low.** NinePocket lists Champion's Path under
the Sun & Moon to Sword & Shield method. No other source was found.

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo |
| 7 | Rare slot |
| 8 | Basic Energy |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- Which end faces the wrapper front: Unknown.
