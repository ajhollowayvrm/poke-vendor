# Astral Radiance (2022)

Set data for Astral Radiance. See [../13-sets.md](../13-sets.md) for the
approach. See [eras/sword-shield.md](eras/sword-shield.md) for the era
template and the evidence behind the pack order.

## Release

- English release: May 27, 2022.
- Set code: SWSH10. Abbreviation: ASR. TCGplayer set code: SWSH10.
- Cards: 246 total. 189 in the main numbering, plus 27 secret rares, plus 30
  Trainer Gallery cards.

## Pack structure

- Bulbapedia: "Each Astral Radiance booster pack contains ten cards from the
  expansion, a code card for use with the Pokémon Trading Card Game Live, and
  either a basic Energy card or a VSTAR marker card."
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo
  slot, 1 rare slot.
- TCGplayer: "Roughly 1 in 8 Astral Radiance booster packs contain a Trainer
  Gallery card in the Reverse-Holo slot."
- Radiant slot: Unknown for this set.

## Pack order

**Confidence: community guide.** NinePocket lists Astral Radiance and its
Trainer Gallery under the Sun & Moon to Sword & Shield method.

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo slot (can be a Trainer Gallery card) |
| 7 | Rare slot |
| 8 | Basic Energy or VSTAR marker |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- A Trainer Gallery hit sits next to the rare slot, near the middle.
- With the community pack trick, the rare is last.
- Which end faces the wrapper front: Searched 2026-09-12: no source found (see the era file, which also resolves the code card's physical position).

## Special subsets or mechanics

- Trainer Gallery (30 cards) in the reverse holo slot.
- First set with Radiant Pokémon (3 cards).
- TCGplayer: the gold-on-black Shadow Rider Calyrex VMAX and Ice Rider
  Calyrex VMAX are "about twice as common as their alternate-art Trainer
  Gallery versions."

## Slot map

How the game builds one pack from the card list. Each row is one
outcome of one slot. The game picks one outcome for each card in the
slot, then picks one card at random from the cards that match the row.

- **Slot** and **Count** come from the pack structure above.
- **Rarity list entry** links the outcome to the stop rule.
- **TCGdex rarity** and **Variant** match the card list exactly.
- **Cards** limits the matching cards: `All`, `Nos. a–b`, `Not nos. a–b`,
  `Part: <card list table>`, or `Category: <category>`.
- **Odds in slot** is the chance of the outcome for one card in the
  slot. `Rest` is the remainder. `—` means no source gives the odds.
- A variant that no row uses does not come from booster packs.

Confidence: the era template gives the slots. This set's Radiant slot
is Unknown; the map puts it in the reverse holo slot, matching Crown
Zenith, a later set in this era with a confirmed Radiant slot. TG29 and
TG30 also have a Holo (Gold) print; the map uses their plain Holo
print, matching the other Trainer Gallery secret rares.

- The TCGplayer study has no Radiant figure and no holo rare figure. The only
  figures are from a 615-pack community sample.
- Radiant slot (rare slot or reverse holo slot): Searched 2026-09-12: no
  clear source found. Crown Zenith, a later set in this era, confirms its
  Radiant cards use the reverse holo slot; this set's slot is still
  unconfirmed.
- TCGplayer text errors: it says "18 Secret Rare Pokémon cards ... with a gold
  finish". Bulbapedia lists 9 gold secret rares. It also calls the
  alternate-art cards "six full-art trainer cards". The table values look
  correct.

  source found (see the era file). The code card's physical position is
  resolved at the era level.

- **Rarity list odds:** TCGplayer gives one combined figure (3.47%) for Pokémon VMAX or VSTAR. No source splits Rare VSTAR from Rare VMAX, so both entries use the combined figure.
