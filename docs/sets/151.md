# 151 (2023)

Set data for Scarlet & Violet—151, the first special set of the Scarlet &
Violet era. The shared pack template, pack order, and rarity system are in
[eras/scarlet-violet.md](eras/scarlet-violet.md). This file records the set
data and every exception. See [../13-sets.md](../13-sets.md) for the general
approach.

## Release

- **English release:** September 22, 2023.
- **Set code:** MEW.
- **Card count:** 207 cards. The main set has 165 cards. The secret rares are
  42 cards, numbered 166/165 to 207/165.
- The Japanese set, Pokémon Card 151, has 210 cards. Do not use the Japanese
  count.

| Part | Rarity | Cards |
|---|---|---|
| Main set | Common | 66 |
| Main set | Uncommon | 62 |
| Main set | Rare | 25 |
| Main set | Double Rare | 12 |
| Secret rares | Ultra Rare | 16 |
| Secret rares | Illustration Rare | 16 |
| Secret rares | Special Illustration Rare | 7 |
| Secret rares | Hyper Rare | 3 |

The counts come from the Bulbapedia set list. TCGplayer gives the same
counts.

## Pack structure

12 cards per pack: 10 set cards, 1 Basic Energy card, and 1 code card.

| Slot | Count | Can hold |
|---|---|---|
| Common | 4 | Common |
| Uncommon | 3 | Uncommon |
| Reverse holo slot 1 | 1 | Reverse Holo |
| Reverse holo slot 2 | 1 | Reverse Holo, Illustration Rare, Special Illustration Rare, Hyper Rare |
| Rare slot | 1 | Rare, Double Rare, Ultra Rare |
| Basic Energy | 1 | Basic Energy card, or a Cosmos Holofoil Basic Energy card |
| Code card | 1 | Pokémon TCG Live code card |

**Confidence:** era-wide sources (PokeBeach report before release, Bulbapedia
table). TCGplayer's opened-pack study confirms the slot for each rarity and
the foil Energy in this set.

**Exception:** the Basic Energy slot can hold a Cosmos Holofoil Basic Energy.
The Energy cards come in eight types: Darkness, Fighting, Fire, Grass,
Lightning, Metal, Psychic, and Water (TCGplayer).

## Pack order

| Position | Slot |
|---|---|
| 1–4 | Common |
| 5–7 | Uncommon |
| 8 | Reverse holo slot 1 (Reverse Holo only) |
| 9 | Reverse holo slot 2 (Illustration Rare, Special Illustration Rare, Hyper Rare) |
| 10 | Rare slot (Double Rare, Ultra Rare) |
| 11 | Basic Energy (can be Cosmos Holofoil) |
| 12 | Code card |

**Confidence: industry news report before release** (PokeBeach, era-wide).
No source in this research shows an opened pack of this set card by card.

- **Double Rare and Ultra Rare:** card 10, the third card from the end. It is
  one of the last three cards.
- **Illustration Rare, Special Illustration Rare, and Hyper Rare:** card 9,
  the fourth card from the end. It is not one of the last three cards. If the
  rip screen hides the code card, card 9 is the third card from the end.
- **Cosmos Holofoil Basic Energy:** card 11, the second card from the end. It
  is one of the last three cards.
- **Conflict (last card):** TCGplayer's 151 study says: "the last card in a
  pack of 151 is a Basic Energy card". This source opened packs of this set.
  PokeBeach puts the code card last. Confidence for each: TCGplayer is an
  empirical study, but the statement is one sentence with no count.
- **Conflict (Hyper Rare slot):** see the era file.
- **God pack cards:** the position of each god pack card is Unknown.

Other figures:

- **Special Illustration Rare Charizard ex:** 0.44% per pack (TCGplayer).
  Empirical study.
- **Illustration Rare Caterpie:** 0.17% per pack. This is below the

  uses the table.

## Special subsets and mechanics

### Cosmos Holofoil Basic Energy

About 1 in 4 packs holds a Cosmos Holofoil Basic Energy in the Basic Energy
slot (TCGplayer). Other sets in this era have no foil Energy in this slot.

### God packs and demi-god packs

Sources report god packs in English 151. The details conflict.

- **TCGplayer (empirical study team):** "The existence of God Packs in 151,
  which contain the Illustration Rare and Special Illustration Rare versions
  of the complete evolution line of one of Kanto's starter Pokémon". It says
  god packs are "so rare" that they do not change the rates. It gives no
  count or odds.
- **Pullmarket (community guide):** calls the English pack a demi-god pack
  with "3 SIRs from one starter's full evolution line + 7 Illustration
  Rares". It gives odds of "roughly 1 in 500–1,000 booster packs". Confidence:
  community estimate. No official rate exists.
- The two descriptions do not agree on the cards in the pack.
- The slots that the god pack cards replace: Unknown.
