# Rebel Clash (2020)

Set data for Rebel Clash. See [../13-sets.md](../13-sets.md) for the
approach. See [eras/sword-shield.md](eras/sword-shield.md) for the era
template and the evidence behind the pack order.

## Release

- English release: May 1, 2020.
- Set code: SWSH2. Abbreviation: RCL. TCGplayer set code: SWSH02.
- Cards: 209 total. 192 in the main numbering, plus 17 secret rares.

## Pack structure

- 10 game cards, 1 basic Energy card, and 1 code card for the Pokémon Trading
  Card Game Online.
- Slots (era template): 5 commons (derived), 3 uncommons, 1 reverse holo,
  1 rare or higher.
- No subset in this set.

## Pack order

**Confidence: community guide** (era template, no set-specific source).

| Position | Reveal starts at the commons end |
|---|---|
| 1–5 | Commons |
| 6 | Reverse holo |
| 7 | Rare slot |
| 8 | Basic Energy |
| 9–11 | Uncommons |
| 12 | Code card |

- The rare is **not** one of the last three cards in either direction.
- With the community pack trick, the rare is last.
- Which end faces the wrapper front: Searched 2026-09-12: no source found (see the era file, which also resolves the code card's physical position).
