# Unleashed (2010)

Set data for HS—Unleashed. This set uses the era template in
[eras/heartgold-soulsilver.md](eras/heartgold-soulsilver.md). See
[../13-sets.md](../13-sets.md) for what a set file must cover.

## Release

| Item | Value | Source |
|---|---|---|
| English release | May 12, 2010 | Bulbapedia |
| Japanese equivalent | None. It compiles cards that the first English set did not use | Bulbapedia |
| Set code | HGSS2 | Bulbapedia |
| Abbreviation | UL | Bulbapedia |
| Set symbol | File "SetSymbolUnleashed.png" on Bulbapedia | Bulbapedia |
| Card count | 96: 95 numbered cards and 1 secret rare | Bulbapedia |
| Secret rare | Alph Lithograph TWO | Bulbapedia |

Bulbapedia says the set includes the cards from HeartGold Collection and
SoulSilver Collection that HeartGold & SoulSilver did not use. It also
includes new cards from the Battle Starter Decks and most new cards from the
Leafeon vs Metagross Expert Deck.

## Pack structure

- 10 cards per pack. This follows the era template.
- 36 packs per booster box. Confidence: community. The PokéBeach Card Ratios
  thread uses 36-pack boxes in its per-box figures. No retailer page for this
  box was checked.
- Slots: 5 common, 3 uncommon, 1 reverse holo, 1 rare (community
  description).
- A Prime replaces the reverse holo (Bulbapedia, PokéBeach).
- The set list has no basic energy cards. Packs of this set cannot contain a
  basic energy card from this set.

## Pack order

This set follows the era pack order. Confidence: community claim.

| Card (front facing the player) | Slot |
|---|---|
| 1–5 | Common or uncommon, random order |
| 6 | Reverse holo, or a Prime |
| 7 | Rare slot: rare, holo rare, LEGEND half, or Alph Lithograph |
| 8–10 | Common or uncommon, random order |

- **The rare slot is card 7. It is not one of the last three cards.**
- A Prime is card 6. It is not one of the last three cards.
- cardcollector.co.uk lists "HS Unleashed" by name as "3 cards to the back".
- NinePocket says this era has no reliable pack order. See the era file.

## Special subsets and mechanics

- **Pokémon LEGEND pairs.** This set has three LEGENDs, and each shows two
  legendary beasts. Each LEGEND has a top half and a bottom half.
- **Pokémon Prime.** Six Prime cards take the reverse holo slot.

- **Rarity list order:** Rare Prime uses 1 in 7 from PokeBeach Card Ratios' final post. An earlier version of the same post gives 1 in 5.
- **Rarity list order:** Rare Holo LEGEND uses 1 in 9 to 1 in 12 from PokeBeach Card Ratios. This set has 6 LEGEND halves, more than most sets in the era, so the rate can differ.
