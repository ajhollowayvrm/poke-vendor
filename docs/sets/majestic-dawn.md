# Majestic Dawn (2008)

Set data for Diamond & Pearl—Majestic Dawn. This set uses the era template
in [eras/diamond-pearl-platinum.md](eras/diamond-pearl-platinum.md). See
[../13-sets.md](../13-sets.md) for the general approach.

## Release

- English release: May 21, 2008.
- Set number: DP5. Abbreviation: MD.
- Set symbol: Bulbapedia shows a set symbol image. This file does not
  describe it.
- Card count: 100. Secret cards: 0.
- Bulbapedia: the English set has most cards from the Japanese Dawn Dash
  expansion.

## Pack structure

- 10 cards: 5 Common, 3 Uncommon, 1 Reverse Holofoil, 1 rare slot. Source:
  Bulbapedia (era template).
- The rare slot can hold a Rare, a Rare Holo, or a Rare Holo LV.X.
  Confidence: community reference.

## Pack order

The era template applies. Summary:

- The rare slot card is card 7 of 10. Three cards follow it. It is **not**
  one of the last three cards. Source: Card Collector ("3" cards to the
  back). Confidence: community guide, no method. The position is derived.
- NinePocket says no reliable order exists for packs from this period. The
  two sources conflict.
- The reverse holo position and the common and uncommon order: Unknown.
- No code card. No separate Energy slot. Which end the cards face: Unknown.

## Special subsets and mechanics

- All seven Eevee evolutions appear, with the debut of Glaceon and Leafeon
  (Bulbapedia blurb).
