# 🃏 PokéVendor — Rip · Grade · Sell

A single-player vendor simulation: buy sealed Pokémon product, rip packs with an
animated reveal, price your hits at real market value, send the gems off for
PSA-style grading, and sell for profit. Built for personal, non-commercial play.

## Data
Real sets, cards, rarities, images, and **TCGplayer/Cardmarket prices** come from a
conglomerate of FREE APIs — **[pokemontcg.io](https://pokemontcg.io)** (primary),
**[TCGCSV](https://tcgcsv.com)** (sealed products + per-field price fallback), and
**[TCGdex](https://tcgdex.net)** (last-resort image/price fallback). **Real PSA graded
sale comps** (eBay medians, used for graded card values) are preserved in the shipped
snapshot. No API key is required. A snapshot ships in `src/data/sets.json` (modern +
vintage English sets).

To refresh the snapshot:
```bash
npm run fetch-data                       # no key needed — this is the normal way to run it
ONLY=sv8pt5,me5 npm run fetch-data       # refresh just these sets (merge-preserving)
```

### If the fetch reports stale sets
A set that fails every attempt keeps its **previous** data, and the run says so at the end:

```
🔴 7 of 166 set(s) FAILED and kept their previous data — this snapshot is PARTIAL.
```

That is almost always api.pokemontcg.io being unwell, not you being throttled. It serves
`500`/`502` during an outage and never `429`, and sends no rate-limit headers at all. Check
with `curl -s -o /dev/null -w '%{http_code}\n' 'https://api.pokemontcg.io/v2/cards?q=set.id:base1&pageSize=1'`
a few times — if you see 5xx, wait rather than retry harder. Then re-run slower:

```bash
FETCH_RETRIES=12 FETCH_BACKOFF_MS=3000 SET_DELAY_MS=2000 npm run fetch-data
```

The run already retries failed sets a second time before giving up, because the outages
are bursty.

> **On API keys.** `POKEMONTCG_IO_KEY` is still honoured, but **do not go looking for one** —
> pokemontcg.io's free key tier is being retired in favour of **Scrydex**, its paid successor
> (from $29/month, metered per request, no free tier). Unauthenticated access still works and
> is what this project has always used. A key would only raise a daily ceiling a full run
> (~350 requests) never reaches, and it cannot help with a `500`.

## How to play
1. **Buy** — each set sells its **real sealed product lineup** at **live TCGplayer market prices** (via the free [TCGCSV](https://tcgcsv.com) bulk export, baked into the snapshot): Booster Pack, Sleeved Pack, 2-/3-Pack Blister, Mini Tin, Booster Bundle, Elite Trainer Box, Premium / Super-Premium Collection, Surprise Box, Booster Box — whatever that set actually has. Each rips into its true pack count; ETBs/tins/blisters/premiums add a guaranteed promo (🎁). A single booster pack opens the animated rip. Multi-pack products rip instantly into your collection by default — or, with **⚙️ → Open multi-pack product one pack at a time** turned on, you crack each pack individually with the full reveal (and a **⏩ Skip rest** button to fast-forward whenever you've had enough). You start with $2,500 of seed capital. Ripping sealed is realistically **-EV** — the chase is the point.
2. **Rip** — click the pack to tear it open; cards reveal one by one. The pack-done controls (**Next pack** / Finish) and a running **Hits** list (sorted by value) sit at the **top**; a **Now revealing** callout on the left names every card as it lands (art, rarity, value) and the cards fill the centre. Cards have a subtle pointer-tracked 3D tilt on hover; **rarity is shown by the card's border colour** (common → gray, up through gold/pink for the chases) so the artwork is never covered. Tune the experience in **⚙️ → Rip speed** (Slow / Normal / Fast / Turbo) and **Auto-open next pack** (in one-at-a-time mode, auto-rips the next pack a few seconds after each finishes).
   - **Special foils** (Prismatic Evolutions & Black Bolt): a card in the reverse slot can come as a **⦿ Poké Ball Foil** (~1 in 3, **3× value**) or, in Prismatic, a chase **◉ Master Ball Foil** (~1 in 19, **55× value** — real ones trade at 40–80×) — each with its own badge and border colour, called out in the side panels as it reveals.
   - **GOD PACKS** 🎉: ~1 in 2,500 Prismatic/Black Bolt packs is a god pack where **every one of the 10 cards is a top-rarity hit** — longer suspense shake, a rainbow "GOD PACK!!" banner, a glowing reveal row, and a sustained confetti finale.
3. **Collection** — one unified, value-sorted grid of raw cards and graded slabs; clean borderless art. (The tab also holds **Grader** and **Prices** as sub-tabs.) Every card is valued at live market price. Click a card to move it three ways:
   - **Quick sell** — instant cash, but only **50% of market**, and each one you make in a day pays a little less than the last (a fire-sale floods the buylist). Dumping something genuinely valuable this way also dents your reputation. It is the panic button, not a sale.
   - **List on your site** — pick an asking price with the quick **% buttons (80/90/100/110)** or a custom number. Real **customers browse** your listings as days pass: each buyer has a savvy level (casual → average → sharp → deal shark) that sets how far over market they'll pay. A fair price finds a willing buyer fast; an overpriced card just keeps drawing lookers and **never sells**. Your notoriety and the card's desirability widen how high you can push. Browsers who think it's a bit high may leave a lower **offer** you can accept or decline. Tick **🐦 Tweet it** to post the listing — a ~3-day hype window pulls extra Twitter-mutual eyes (and a notoriety bump). Manage it all on the **Sell** tab — views, offers, **reprice or pull** — minus a ~5% marketplace fee **plus shipping & packing** on every online sale. Sales pay out as the days tick by. **Offers only come on cards you've listed/tweeted** — until you open a brick-and-mortar store, when in-person walk-ins can also make offers on anything in your case. With a store you can also list a card **🏬+🌐 everywhere** — the same physical card is up on your site *and* out in your store case, sold from whichever channel finds a buyer first; an in-person sale skips the fee + shipping and earns the +12% counter premium, so in-store always nets more on the same card.
   - **🔨 Auction it** — no ask, no pulling out: it runs for 3/5/7 days and whoever turns up sets the price. What decides that price is how many bidders your **name** pulled — a nobody's auction gets robbed at ~0.6× market, a known dealer's gets a bidding war past 1.1×. The one exit that gets structurally better as your reputation grows. Optional **reserve** puts a floor under it, at the cost of thinning the very room that sets your price; miss it and the card comes home having spent the days for nothing.
   - **Consign** — a service sells it in a few days for a bit **above** market, minus an 18% fee, so you net roughly 0.84–0.94× market.
4. **Grade** — from a card's detail view, pick a **grading company** and a service tier. All three grade identically strictly — what differs is the fee, the wait, and what the returned slab is worth: **🟥 PSA** is the benchmark every price in this game is quoted against; **🟨 CGC** is a third cheaper and nearly twice as fast at ~15% less on resale (the way you slab a mid stack without parking your capital); **🟦 BGS** is dearer and slower and trades ~8% under PSA, *except* that all-10 subgrades come back a **⬛ BLACK LABEL** worth multiples of the same card in red. Then Economy/Standard/Express on top. Subgrades for centering/corners/edges/surface roll into a PSA 1–10. A 10 can 5× the value; low grades genuinely destroy it. It's a gamble.
5. **Grader** (a sub-tab under **Collection**) — cards and 📦 sealed product out at a grader, each on its own clock, resolving as the days pass. Grading starts **expensive** ($25 / $75 / $150 list, before the declared-value ladder on anything pricey), but builds a **relationship**: total cards submitted climb a loyalty ladder (New → Bronze 5 → Silver 15 → Gold 40 → Platinum 100) that cuts fees 10% → 20% → 30% → 45% across all service tiers. The Grader sub-tab shows your tier, progress to the next, and current discounted fees.
   - **📊 Population reports** — a slab is not one asset. Every card carries a **census**: how many copies exist at that grade. A PSA 10 with 40 in the population is worth a real premium over the comp; one with 9,000 barely gets anything for the holder, and most modern chase cards are the second kind. The **🔭 Grading Scope** prints the actual figure; without it you get the shape ("Scarce", "Flooded") but not the number. **Your own submissions count.** Every slab that comes back adds one, so putting ten copies of a thin vintage card in holders lowers what all ten are worth — which is why "grade everything" is the wrong answer.
   - **🔨 Crack a slab** — break a card out of its holder and send it again. The play a dealer makes on an under-graded slab bought cheap, and it is not a free reroll: the grade a card already earned is *evidence* about the card, so each crack revises its hidden cut toward what that grade implied — and the revision **converges**. Crack the same card four times and the estimate stops moving; it is simply what it is. On top of that, a strong slab is worth more than the raw card inside it, so cracking costs you before the new fee is even paid, and about **5% of cracks nick the card** (which caps every grade it can earn afterwards). Because you pick the company on the way back in, **cross-grading** — a CGC 9 sent to PSA — falls out of the same button.
   - **📦🔟 Sealed grading** — send a sealed product to **🟪 WATA** or **🟨 CGC** and get the box back in a holder. This is a **vintage** play and the game says so: a graded 1999 wrapper is worth multiples, retired modern product gets half that ladder, and anything still in print earns almost nothing for the fee. An old wrapper also rarely gems (a 25-year-old box has been in somebody's cupboard), which is exactly why an unsearched 10 is worth what it is. The panel warns you off the submissions that cannot pay for themselves.
6. **Stats** (in the **⚙️ menu**) — net worth, cash, collection value, realized P/L, notoriety, packs opened, cards/hits pulled, **best pull & best foil ever**, **god packs hit**, cards graded, shows attended, wants filled, goals completed, cards owned — plus the full transaction ledger, and a **🧾 Books** sub-tab holding the quarter's revenue, deductions, tax due and audit exposure alongside the bank's loan desk.

### Card shows (the big mode)
7. **Shows** — a 30-day calendar of card shows across tiers (Local Meetup → Card Shop Event → Regional → National Expo → **Invitational** → **World Championship**). Higher tiers unlock with **notoriety**; bigger shows have higher-value stock and more foot traffic. Elite-tier showcase pieces are **real cards at real prices**: five-figure slabs drawn from actual PSA sale comps in the data (PSA 10 Aquapolis Umbreon ~$49k, Skyridge Charizard ~$35k, Shining Mewtwo ~$36k…) — a card marked 👑 GRAIL genuinely commands that money. Pay an entry fee to attend (up to $2,500 for Worlds).
   - **Opportunity cost (time):** attending a show consumes its **days** — 1 day for a Meetup/Shop, 2 for Regional/National, 3 for an Invitational, **4 for Worlds**. The calendar jumps past the show, and any other shows that fell in that window are **missed**. Blow 4 days at a too-rich Worlds and whiff, and you've skipped every cheaper show those days — choose deliberately. The month auto-rolls a fresh calendar when day 30 passes.
   - **📬 Pre-show leads:** a few days ahead of a show, people reach out — a recurring dealer you have rapport with **sets aside a sealed vintage pack at a held, under-market price**, or a collector **arranges to meet you there** to buy a specific card at an appointment premium (fatter than a normal want — the extra is for making the trip). Leads show on the calendar card and in the log; **skip the show and they're gone.**
8. **The floor** — a **vendor directory** sized to the show: a Meetup lists 16 tables; a World Championship lists 72. Every table is one line — name, archetype (color-coded left edge: fair / sharp / lowballer / high-roller / newbie), what they pay for your cards, how deep their bin is, sealed on the table (🗝️ flags vintage), their priciest showcase piece, and a live **👥 crowd count** as shoppers drift between tables. **Tap a line to browse the booth.** Familiar roster dealers show a 🤝 and your rapport tier; a vendor holding a pre-show item for you is pinned to the top in gold.
   - **🏃 You are not the only dealer here.** Rival dealers work the floor alongside you and they go for the money — the biggest genuinely under-market card left in any bin. A banner names who took what, off whose table, and how far under market it went. Two things keep it fair: you always get a **grace period** to look around when you arrive, and they **only ever take real deals** — a fairly priced card is never sniped. So what you lose is exactly what you should have been quicker about, and the bigger the hall the sharper the competition (a local meetup barely has any; a World Championship floor is full of people who do this for a living). This is what makes the **🤝 Dealer Network**, which flags a deal on sight, worth its price.
9. **Vendor stock** — each booth carries a deep bin of 14–31 real cards, with its 1–3 priciest pieces called out in a **⭐ Showcase case** above the bulk bin. Newbies sometimes *misprice a gem*; the Dealer Network upgrade flags DEAL/OVER.
   - **Live rippers** 📦: ~30% of the crowd are cracking sealed product as they browse. When one hits something big — a Special Illustration Rare or better, a Poké Ball / Master Ball foil, or a **god pack** — they **announce it to the whole hall**: a banner shows who pulled what (with the card) **and at whose table**, and everyone turns to look (~6% of rips). And if that lucky ripper **bought their sealed from your booth**, the hype rubs off — your notoriety bumps (+2, or +5 for a god pack), and the banner turns green to say so. The more famous you are, the bigger your share of the floor's rippers are running your product (≈10% at zero rep → ~55% once well-known).
10. **Encounters** — visitors walk up to your booth: lowball/fair **offers** on your cards, **questions** about card values (answer right to gain notoriety), browsers, **many-to-many trades** (they bundle several of their cards for several of yours — cards and even your sealed — with cash balancing the gap; accept or pass), and people who got **fleeced next door** — give them a card free to *make their day* (big notoriety). A cooldown spaces walk-ups so even the 600%-traffic Worlds floor doesn't spam you. Procedurally built from templates + real cards.
    - **Vend sealed too** — when you book a booth (ShowPrep) you can pack **sealed product** (ETBs, boxes, packs) onto your table alongside cards. Floor shoppers buy it at market, and any unsold sealed comes home to your 📦 inventory when you leave.
    - **Bundle trades at other booths** — at a vendor's table, **🔁 Trade** opens a builder: pick any mix of **your cards + held sealed** to offer, and any mix of **their cards + sealed** to take; cash auto-balances the value gap (your side valued at their buy rate).
11. **Sell** — you start as a **solo online flipper working from home**: orders arrive **per game-day** from marketplaces and DMs (Reddit, eBay, Discord, etc.), scaled by notoriety. Days pass on the **real-time clock** (and several at once when you attend a show), bringing customers in. No one shows up in person yet — open a store for that. The Sell tab also shows your active listings/consignments up top. Each order is the same encounter engine (offers, questions, price checks, helping someone who got scammed in a trade); the inbox is capped, so ignored orders eventually drop.
    - **Away at a show = home shop opportunity cost.** The days you spend at a show pass at home too. Without remote-management upgrades, the home orders generated during those days are **missed**: the **📱 Smartphone** keeps *online* orders coming while you're away, and the **🧑‍💼 Shop Assistant** (needs a store) handles *walk-ins*. The ledger tells you exactly what you missed.

### Going physical & payments
12. **Payment methods** — you start accepting **only Venmo**. Every buyer prefers a method; if you can't accept it, the sale falls through (small notoriety ding). Each rail is its own upgrade. **Cash** comes with the store. Online buyers use Venmo/PayPal/cards; in-person can also use cash and tap. **Processing fees:** card rails skim a cut of each sale (PayPal/Cards ~2.9%+$0.30, Tap ~2.6%+$0.10); Cash and Venmo are free. The result message and ledger show the net after fees — so an all-cash/Venmo flip keeps more than the same sale on plastic.
13. **Brick-and-Mortar Store** — the major mid-game upgrade ($8,000). Opens a physical shop: **in-person walk-in customers** start arriving (on top of your online orders), and you can accept **Cash**. Card *shows* stay open from the start regardless — the store is specifically about home/local foot traffic.
    - **Stock the shelf with cards *and* sealed** — walk-ins buy whatever you put out. Stock singles from **Cards → Select → 🏬 Stock shop**, and **sealed product** from **📦 Inventory → 🏬 Stock** (or **Stock all to shop**). Manage the shelf and pull items back on the **Sell** tab.
    - **Bulk & quantity moves** — on the 📦 Inventory tab, list or stock a **quantity** of a stack at once (e.g. 4 of your 10 booster packs), or **List all online** / **Stock all to shop** in one click.
    - **📦 Tap any sealed product to inspect it** — sealed on your shelves (Storeroom / Floor / Personal) is more than a look-alike thumbnail: tap it for a detail card showing **what it actually is** (full product name, set & release, pack count, live market value and **your cost basis** vs market, and what it **breaks down into**), plus the same rip / break / stock / list / flip moves. It also reads the set's **chase density** — what **% of the set's hits** would clear **$100 graded PSA 10** — and opens a **📋 full set price sheet** (lazy-loaded on tap): every card in the set with its raw value and **PSA 10 / PSA 9** "if it gemmed" estimates, **value-sorted** so a top-heavy chase set reads apart from a deep one (a Skyridge) at a glance. Searchable and re-sortable by value / rarity / number / name.
    - **Walk-ins ask for things** — a share of customers come in *hunting a specific item* (a sealed product or a single). Have it **on the shop floor** → an instant happy sale; only in **the back** (the storeroom) → grab it from the back; **don't own it at all** → they leave disappointed (a small rep ding), and the miss lands on the **📊 demand board** — a "what the town's asking for" panel on the Shop floor tab tallying a fortnight of unfilled requests, so you stock what locals actually hunt. (🔒 Personal keepsakes are invisible to customers — not for sale means not for sale.)
    - **🗓️ The week has a shape** — walk-in traffic, the counter, and the pack machine swell **Friday–Sunday** (Saturdays ~1.45×) and thin midweek (dead Tuesdays), and **collection sellers cluster on weekends** (attic-cleaning is a Saturday job). Online is 24/7. The header clock shows the weekday.
    - **📆 …and so does the year** — the calendar maps to real months (the game opens in September). Back-to-school and summer boost the kid channels (pack machine, bulk bin), January lulls, and **November–December is the gift rush**: more traffic, plus **🎁 gift buyers** — "something for my nephew, about $40?" — who buy the best floor sealed in budget at a gift-wrap premium (a miss feeds the demand board). A December Saturday is the biggest day of the year.
    - **🗑️ The bulk bin** — the quarter box kids dig through, and the busiest fixture on your floor. Toss sub-$1 raw cards in (keep-singles/locked protections apply), set a flat price, and the day-tick counts **diggers**, not cards: each one works the box for twenty minutes and walks out with a **handful**, so a healthy 25¢ box clears ~14 cards a day for an unknown shop and **~50–90 a day** once you're a name (the 🗑️ Second Quarter Box lifts the rail 90 → 200). That's ~5× the LGS turn-in rate — the patient path; instant LGS credit stays as the fast one. Price is the throttle: a dime box gets mobbed, a dollar box of chaff sits.
      - **…and an empty box is a missed sale.** Diggers who walk up to a bare bin leave unhappy — a rep ding, a line on the demand board, and **pent-up demand** that makes the day you finally refill it a rush. Let it sit empty and the kids start giving up (a fortnight in, the town forgets the box entirely and stops costing you — but you have to win the diggers back). Set the price to **$0** to take the box off the counter cleanly: no sales, and nobody comes looking. The panel shows what the box will clear per day and **how many days of stock** you've got left, and the ⚙️ *keep the box full* toggle sweeps storeroom bulk in every morning (never your display floor).
      - Now and then a kid digs out something you shouldn't have tossed (+1★, best day of their week) — the bin panel warns you what's buried so you can fish it back out.
    - **📰 Reprint waves** — hot sets restock in announced waves, like real modern Pokémon. The announcement **softens that set's market 8–15%** (reprint incoming!); then a 5–8 day **preorder window**: commit up to your **allocation** (scales with distributor rapport) at a locked wholesale price, while locals put **deposits** down at your counter. On **drop day** the stock lands, deposit-holders pay their balance at retail+premium (short them → refunds and a grudge), and a 2-day **launch rush** sends hunters through the door asking for exactly that set. Over-committing is a real bet — stuck inventory in a dipped market.
    - **🧢 Supplies rack** — sleeves, toploaders, deck boxes, binders, playmats, dice: the ~50%-margin steady trade that pays a real shop's lease. Buy wholesale **by the case** on the Shop floor tab; units sell at retail with the day's footfall, and **league/tournament nights burst-clear the rack** (players sleeve decks at the table).
    - **The 🏬 Shop floor tab** (under **Sell**) runs the store in sections: **stocked singles**, **stocked sealed**, the **consignment case**, and the **giveaway** lever. The Orders sub-tab groups your inbox into **🔁 Trade offers**, **🙋 Walk-in requests**, and **💰 Offers & browsers**.
    - **🔒 Holds for regulars** — set a shelf item aside for a named regular: it comes off the sellable floor, and within ~4 days they come in and buy it at a premium over the walk-in price (trust-scaled odds, +trust on pickup). If they no-show, it goes back out.
    - **🧾 Consignment intake** — once your shop has a name, locals bring THEIR cards for you to sell: their price, your **15–25% commission**, zero capital down. Accept or pass; sold pays your cut (+notoriety as the shop-to-sell-through), unsold goes home with its owner after ~a week.
    - **🎁 In-store giveaways** — give a card to the locals: a notoriety pop scaled by the card's value (the 🎗️ Charity Banner boosts it), **+35% walk-in traffic for 3 days**, and every regular's trust warms. The loss-leader lever for a slow week.
    - **🛍️ Collection buy-ins + 💳 store credit** — locals walk in wanting to SELL you a lot of cards. You never see the exact cards first: you get a noisy eyeball **appraisal** (±25%; the 🔍 Loupe tightens it to ±8%) plus a seller read ("just wants it gone" vs "checked comps"), against their cash ask (45–70% of true market). Pay **cash**, or pay **store credit at +25%** — no cash leaves the till, the seller tends to become a regular, and the credit drains out of your daily counter takings over time (with ~2%/day breakage that's never redeemed). Outstanding credit counts against net worth, and locals stop taking credit if you float too much of it. **🤝 Haggle the ask** (up to 2 rounds): every seller has a hidden floor — estate sellers leave real room, comp-checkers barely budge, crown-jewel lots are priced firm — and pushing too far loses the *whole lot* to the shop across town. The seller read is your tell. **🛍️ Post your buylist rate** (the sign on the counter): *tight ~40%* pulls fewer sellers at fatter margins, *generous ~70%* pulls ~50% more at thinner ones — and generous cash sellers tend to become regulars. Volume vs margin; your call.
    - **🏪 The shop across town** — you are not the only card shop in this town. A named rival opens the day you do, and their **share of the local trade** is a daily tug-of-war: it climbs for free every day you coast, and comes back down when you host nights, run giveaways, post a generous buylist, keep a full shop floor, and build a name. Let them get far enough ahead and they start running **promotions you can feel in your own footfall** — a 20%-off sealed weekend across town is fewer people through your door for days.
    - **📇 Special orders** (upgrade) — when a walk-in asks for sealed you don't carry, you get a third answer besides "sorry": take a **35% deposit** and order it in. It's sourced automatically from the cheapest distributor that has it (never spending the till below a day's lease), and they pay the balance at retail **+10%** on pickup. It's a promise, though — miss the date and it's a refund, −3★, and a line on the demand board.
    - **🏬 A second location** (endgame upgrade) — a satellite shop run by a manager you hire, trading at ~40% of the main store's daily volume out of stock **you send it**. It has its own lease and its own payroll whether or not you keep it stocked, it can't touch the main shop's shelves, and if it can't cover itself for a week the manager locks the doors and sends the stock home.
    - **🎪 Hosted events** — plan tonight's event from the Shop floor; it happens when the day turns (then a 2-day breather): **🔁 Trade Night** ($60 — trust for every regular, extra walk-ups, fresh trade offers), **🎮 League Night** ($100 — door + counter money, may mint a new regular), **🏆 Tournament** ($250, 40★ — entry fees in, a big notoriety pop, 2 days of buzz), **🎟️ Raffle Night** ($40 + a prize card — ticket money in, the prize goes home with a winner, giveaway-scale goodwill).
14. **Upgrades** — permanent buy-once gear, priced to scale with the real economy (cheap accessories in the low hundreds → the **Brick-and-Mortar Store at $8,000** as the major store-owner commitment): the three **payment rails**, **📱 Smartphone** + **🧑‍💼 Shop Assistant** (keep earning while at a show), Visitor Ticker (alerts at shows), Glass Cases (higher offers), Jeweler's Loupe (better grade odds), Signage (more traffic), Dealer Network (see vendor deals), Charity Banner (+50% notoriety from generosity), **🧮 Accountant** (deductions + half the audit risk), **🔴 Streaming Setup** (go live and rip on camera — queue multiple products, box breaks) + **🎟️ Live Rip Service** (take viewer rip orders live). You'll need to grind sales before the big ones are in reach.
    - **The service catalog** — a deep bench of buy-once gear across every system: **📲 Tap to Pay** (the cheapest in-person card rail), **📦 Shipping Station** (halves online shipping & packing), **🗄️ Locking Consignment Case** (5 consignments + fatter commission), **📻 "We Buy Collections" Ad** (~40% more walk-in sellers), **🪑 Appraisal Desk** (6 lots waiting + a third haggle round), **🏦 Preferred Account** (credit at 2.5%/mo, 65% limit), **🥤 Snack Cooler**, **🎁 Gift Wrap Counter** (serve December gift buyers from the storeroom), **🎪 Events Coordinator** (one hosted night recurs weekly, faster cooldown), **🗑️ Second Quarter Box** + **🎰 High-Capacity Vend Unit** (deeper bulk-bin & pack-machine rails — the quarter box's 90/day rail genuinely binds at a big name; the Bin Keeper feeds the machine overnight), **✨ Custom Wrap Press** (repacks sell better, sting less), **🏗️ Storage Unit** (+15 free idle-sealed allowance), **🚚 Grader Dealer Account** (turnaround cut ~40% — same odds, faster capital; it covers 📦 sealed submissions too), **🧾 Submission Runner** (auto-submits clearly-+EV raws overnight, pausable in ⚙️), **🎬 Clip Editor** (every stream leaves a clip), **🛡️ Mod Team** (halved sub churn, more raids), and the **🧮 Purchasing Agent** (set REORDER POINTS per product type — "always 2 ETBs of everything" — and every buyable set is topped back up to the minimum overnight, cheapest distributor first at your rapport price, counting stock on hand / at shows / on the boat, cash-only with a till float).
    - **⛩️ Import License** ($6,000, major) — opens **🎌 Japan Direct** on the Buy tab: authentic **Japanese sealed** priced off the real JP singles market (JustTCG prices, TCGdex art). JP boosters are **5 cards** with a **denser hit ladder** than English (ARs ~3 a box, an SR every box, SARs every other box), and boxes run **closer to break-even** — the import play real rippers chase. Orders **cross the Pacific**: paid now, landing in your storeroom **~3 days later** (a 🚢 banner tracks what's on the water; in-transit stock still counts in your net worth). The shelf launches with four fully-priced, fully-illustrated sets (Scarlet ex, Ruler of the Black Flame, Ancient Roar, Paradise Dragona) and **more JP sets join automatically as their data completes** — JP 151 is browsable in the price guide today and goes rippable once its base commons land in a future fetch.
15. **Prices** (a sub-tab under **Collection**) — a reference price guide: pick any set and browse every card with its market value; search by name, sort by number / value / rarity. Shows the set's total value and chase card. The same per-set breakdown — now with **PSA 10 / PSA 9** estimates beside each raw value — is also one tap away from any sealed product's detail card (see the store's sealed inspector above). Multi-day shows also re-roll their vendor floor each day — different booths and stock day to day.

### The dealer's craft
16. **🔨 The auction house** — the game let you *send* a card to auction; now you can bid on one. A board of live lots — raw singles, graded slabs, vintage sealed — runs on the **Buy** tab, and it works the way the real thing does:
    - **You leave a maximum and walk away.** There is no bid-again button on purpose: a proxy maximum *is* the decision, and you pay **one increment over the runner-up**, never your own maximum. A high bid costs nothing when the room is quiet.
    - **The room sets the price.** Every lot shows its **👥 watchers**. A packed lot closes over market; a quiet one closes well under it. Reading which is which is the whole skill.
    - **A quiet lot is quiet for a reason.** This is the trap, and it is deliberate. The lots nobody is watching are disproportionately the ones with one bad photo and an optimistic condition claim — a "Near Mint" that arrives creased, or a sealed box that has been opened, searched and shut again. **🤝 Dealer Network** flags a dressed-up condition claim; **🔬 Authentication Kit** spots a resealed wrapper. Without them you are bidding on photographs.
    - **The house takes 13%** on every win, plus postage. Bidding market value on everything means paying about market once the premium and the bad descriptions are counted — the sim pins that. The edge belongs to whoever waits for a quiet room on something they have actually checked, and it is a **slow** edge: you win a fraction as many lots.
17. **🖨️ Errors & misprints** — the printer gets it wrong now and then, and what falls out of the pack is worth money for a reason that has nothing to do with the rarity symbol. Roughly **1 in 1,250 packs** holds one: badly off-centre, miscut (a strip of the neighbouring card down the edge), crimped by the pack sealer, an ink error, a missing holo layer, an inverted back, or — about once in 125,000 packs — a **wrong back** entirely. An error **sets its own floor**: a miscut common is not worth three times ten cents, it is worth what error collectors pay, so pulling one out of a bulk slot is a real event. And it is worth **less raw than authenticated** — the market discounts a claim nobody has checked, so grading a misprint unlocks the rest of the premium. Badged 🖨️ on the card so a bulk sweep never eats one by accident.
18. **Card condition** — every raw card has a condition: **NM / LP / MP / DMG**. Condition both **scales the card's value** (NM 100% → LP 72% → MP 45% → DMG 20%) and **caps the grade** it can earn (a Damaged card can never grade above PSA 4, MP ≤ 6, LP ≤ 8). Cards pulled from a sealed pack are **always Near Mint** — any flaws only surface as lower subgrades when you grade them; only cards bought off a show floor or bargain bin run rougher. A condition chip shows on any non-NM raw card, and the grader warns you before you waste a fee on a card that can't 10.
19. **Haggling** — at a show booth (and in your own sell flow) you don't have to take the sticker price. Open **Haggle** to make counter-offers across up to **3 rounds**: nudge your offer up or down and the other side either accepts, counters, or **walks away** — and how far they'll bend depends on the booth's **archetype** (a fair dealer meets you halfway; a sharp or a fleecer barely budges; a newbie folds easily). Push too hard and you lose the deal.
20. **Buylist & consignment** — two ways to move cards beyond a straight sale. **Bulk turn-in**: hand your raw sub-$1 bulk to the Local Game Store for **in-store credit at a nickel a card** — which is what bulk is actually worth, and the credit spends on your next order there. **Consign**: hand a card to a shop to sell *for* you; it sells over the next few game-days at a slight markup, and you collect the **net after their 18% cut** when it moves (paid out as the days pass / when you return from a show).
21. **Want-list collectors** — recurring collectors post **wants** (a specific card, or any card from a set/rarity). Fill one from your collection and they pay an **above-market premium** plus a notoriety bump. Wants expire after a few days and refresh as you play; the richer your reputation, the more (and pricier) wants you attract.
22. **Daily goals** — each game-day rolls a fresh set of **2–3 goals** (rip N packs, sell N cards, grade a card, fill a want, attend a show, make someone's day, turn a profit…). Completing one pays out **cash + notoriety**, scaled by your reputation. They live on the Sell tab and rotate every day.

### 🧾 The books

23. **Quarterly tax** — every dollar this game ever paid out used to be tax free. Now the business files. The books run on **cash basis**, which is what a small dealer really does: revenue is money in, and everything you spend on the business — inventory, fees, freight, grading, the lease, wages, booth fees — comes off the taxable line. Three things follow:
    - **A quarter that nets under $1,000 bills nothing**, so an early-game flipper never meets this system at all. It arrives when the business does.
    - **Buying inventory before the quarter closes lowers the bill.** That is not an exploit, it is what cash-basis accounting *is*, and it is what dealers do every December. Sitting on a fat quarter with an empty shelf is the expensive way to play.
    - **The payment rails now cut both ways.** Cash and Venmo skip the processing fee — and a shop that can only take those rails *is* a cash business, which is the profile that gets **audited**. Buying a card rail costs 2.9% of every sale and buys that exposure down. A **🧮 Accountant** finds another 8% of deductions and halves the audit chance outright.
    - An unpaid bill accrues interest, and left long enough the lien **freezes your distributor credit line**. The panel lives on the **Stats → 🧾 Books** tab with a countdown, so a bill can never quietly surprise you.
24. **🏦 The bank** — different money from the distributor line. That one is revolving credit for stock, sized off what you are already worth; this is a **fixed-term note** — a lump sum you pay down daily, the way a shop buys a lease instead of grinding for it. Three notes on the desk, gated by reputation and collateral, and the rate falls sharply as the business proves itself (36% APR on the starter note, 13% on the commercial one — a shop with no trading history does not get prime money). The commitment is not the interest, it is the **daily instalment**, which comes out whether or not the shop had a good day. Miss eight in a row and the note is **called in**: the debt stands, your name takes a real hit, and the distributor line freezes on top. Clearing it early costs only the remaining principal — the interest you never reached simply never accrues.

### Go live (the 🔴 Stream tab)
25. **Rip on camera** — with the **🔴 Streaming Setup** upgrade you go LIVE and crack sealed **from your held inventory** on stream. Viewers tune in (crowd scales with notoriety + followers, and vintage/older sealed draws a bigger room), react in a live chat that names your **actual** pulls, and **tip** — a running **hype train** stacks a tip multiplier as hits chain. Big pulls spike the room; a **god pack** on camera is a real fame jump. Streaming **burns a game-day** and **tires your audience** (over-stream and the room thins until you rest). A hot stream banks notoriety, grows your **followers** (a returning crowd), and pumps all your listings' traffic for days. You can **🎁 give away** any card mid-stream for a follower pop, and each stream has a small **goal** that pays followers.
    - **Queue multiple products** — line up as many held products as you like before going live; the stream rips through them **back-to-back** in one broadcast, and you can **add more from inventory mid-stream** without ending it.
    - **📦 Box breaks** — mark any multi-pack product in your queue as a break: sell **spots** (random teams) up front, rip the box live, and each spot's cards **ship to its buyer** (unsold spots' cards stay yours). A hot pull can sell a lingering spot live.
    - **🎟️ Live Rip Service** (upgrade) — take **rip orders** on stream: viewers pay a **premium** to have you crack a product you hold on camera. You bank the markup **no matter what hits**, rip it live in your queue, and **every card ships to that buyer** — a steady, low-variance income while you broadcast.
    - **📣 Announced streams** — promise a broadcast **1–3 days ahead**, optionally headlining **one card you own** as the night's giveaway. Go live on the promised night for a much bigger room (lead time + prize value stack, up to ×1.8); **deliver the promised card on air** for a rep pop and bonus followers. Skip the night — or bait the room and never raffle the card — and your name takes the hit.
    - **🎯 Chase bounty** — before a rip, promise the room: *"if I pull {card} tonight, chat wins it."* The stakes alone draw a bigger crowd; if it hits, the room detonates (hype train to max, subs pour in) and the pulled copy ships to a lucky viewer. If it never hits, no harm — everyone knew the odds.
    - **❤️ Subscribers** — hype moments, raids, and giveaways convert watchers into **paying channel members** who drip a little cash **every day**. Go dark for over a week and subs start drifting off — the channel wants feeding.
    - **📆 Weekly rhythm** — stream on a steady cadence (every ~3–10 days) and a **loyal crowd** builds, showing up bigger every time (up to +30%). Go dark for 10+ days and the streak forfeits.
    - **💥 Raids** — a room that's popping off can attract another streamer's whole audience mid-stream: a sudden viewer flood, new followers, and a sub or two.
    - **🎬 Clips** — a god pack or a monster pull gets **clipped**, and the clip keeps recruiting followers for days after the wrap — even if almost nobody saw it live.
    - **🛍️ Shelf sales on air** — with the hype train rolling (≥×2), viewers impulse-buy **singles off your store floor** at a stream premium.

### 📱 Content & audience (building a name off-air)
26. **The moments you already make become posts** — going live costs a whole game-day, but filming what you were doing anyway costs a phone. With the **📱 Shorts Channel** every notable moment posts itself — a chase out of a kitchen-table rip, a **gem 10** back from the grader, a collection dumped on your counter, a master set page finally filled — and each one circulates for a couple of days recruiting **followers**. Most do small honest numbers; every so often the algorithm catches one and it **pops**. It's the floor under the channel, deliberately worth a fraction of a broadcast clip.
    - **🃏 Master Set Challenge** — announce a set you're chasing and film the hunt. Show dealers start pulling that set's singles out of their bins for you (same cards, same prices — you just *find* them), every card you land is an episode that recruits followers, and **completing it on camera is the payoff video**: a big follower haul, 🔥 hype and 🎫 clout on top of the completion bonus. Declare a set you're nearly done with and it pays a fraction — that's not a challenge. Declared from the set's page in **Cards → Binder**.
    - **🎥 Show Vlog Kit** — every show trip becomes a "come to a card show with me": followers scaled by the hall and the best thing you came home with, a couple of days of extra listing traffic on the drive back, and **+12% booth traffic at the next show** because people recognize you. Works whether you're vending or just shopping.
    - **🔁 Content Calendar** — moments bank instead of firing all at once and release **one a day**, so a hot rip day feeds a dry week. Post every day and the cadence itself pays (up to +25% reach) — consistency beats bingeing, same as the stream's weekly rhythm.
    - **💬 Community Discord** — turns an audience into a customer base: wants post far more often and **skew toward sets you actually hold**, the board carries one more at a time, and members occasionally become regulars.
    - **🤝 Creator Collabs** — you start guesting on *other* people's channels, so a chunk of their room follows you home at no cost to your own broadcast day. Repeat guests get the better slot.
    - **🎙️ Hobby Podcast** — the slow one: a weekly episode pays **permanent ⭐** rather than heat, and you hear a **reprint wave about two days before it hits the price boards** — a window to sell into the old price.
    - **💰 Brand Deals Desk** — accessory brands sponsor the channel for a **capped monthly check** scaled by followers and subs, against a real obligation: actually feature them by ripping a few packs of their set on camera inside the window. Deliver and the money keeps coming; ghost them and the deal lapses with a rep ding.

**Notoriety** drives everything: how many orders/walk-ins you get, which shows you can attend, vendor deals, want-list volume, daily-goal payouts, and how buyers treat you.

New here? A small **🎓 Getting started** card sits above the game until you've closed the loop once (buy → rip → sell → end the day) — it tracks what you've actually done rather than walking you through a script, and retires itself for good the moment you're through it. The **?** beside your ⭐ notoriety explains what that number actually drives.

Progress auto-saves to **IndexedDB** (the shell's WKWebView keeps a persistent data store, which is why the app is served over a custom scheme rather than `file://`), falling back to localStorage where IndexedDB can't be opened. Reset from the ⚙️ menu.

Saved cards store only what's true of *your* copy — uid, condition, hidden cut, grade,
where it's shelved — and the catalog row (name, rarity, price, comps) is laid back
underneath from `src/data/sets.json` on load, since the app already ships it. A field is
only dropped when the bundled data reproduces it byte-for-byte, so a copy the game changed
is always written out in full. See `src/game/store/slimsave.js`; `npm run verify-slimsave`
round-trips every card in the catalog and prints the save size against the cloud cap.

## Pull rates
The hit-slot rarity ladder (`scripts/fetch-data.mjs` → `HIT_SLOT`) approximates
modern Scarlet & Violet / Mega Evolution English booster pull rates:
Rare → Double Rare (ex) → Ultra Rare → Illustration Rare → Special Illustration
Rare → Hyper Rare (gold) → Mega Hyper Rare (chase). Tweak the weights there.

## Where it runs
**One target: a native app on an iPhone.** The web build exists to be loaded by the iOS shell
in [`ios/`](ios/README.md), which serves `dist/` over a custom `pokevendor://` URL scheme.

There is no PWA and no web deployment. Both were removed on 2026-08-15, and the service worker
turned out never to have run in the first place — *a service worker does not run under a custom
scheme*, so the whole PWA layer was inert inside the only place the app actually runs
(`npm run ios:sim` asserts `sw: false`). Card-art caching is done natively by `URLCache`.

```bash
npm run ios:sim       # build, install and audit in the simulator
npm run ios:device    # build, sign and install onto a connected iPhone
```

## Stack
Vite + React + Zustand. No backend, no tracking, all local. Boot is profiled rather than
guessed at — see [docs/PERFORMANCE.md](docs/PERFORMANCE.md) and `npm run profile`.

## Balance is enforced, not asserted
`npm run sim` boots the real game in headless Chromium, imports the actual engine and store
modules, and Monte-Carlos every money loop the design depends on. It fails the build if an
invariant breaks, which is what lets systems be added without quietly re-tuning the ones
underneath them. Fourteen sections today, including the ones that pin the newest systems:

| # | Section | The invariant |
|---|---|---|
| 1 | Rip EV | every modern set stays **-EV to rip** — the chase is the point |
| 2 | Grading EV | gem odds match real PSA data (blind P10 18–30%) and grading is a real business |
| 3 | Repack EV | player-built mystery packs pay out **less** than they cost |
| 4 | Liquidation | every instant exit is a real haircut (< 1× market) |
| 5 | Storage | the daily fee taxes only the **idle** hoard |
| 6–8 | Reputation · showcase · content | every multiplier rails where it says it does |
| 9 | 📊 Population | the census multiplier averages **exactly 1.0** across the catalog, so scarcity is a spread and not a nerf to grading |
| 10 | 🖨️ Misprints | the whole error category adds **under 1%** of pack EV, so section 1 is untouched |
| 11 | 🔨 Auction house | blind bidding loses; a disciplined bidder wins, slowly |
| 12 | 🔨 Crack & regrade | repeated cracking **converges** — it is not a free reroll |
| 13 | 🧾 Tax · 🏦 loans | the bill is progressive, restocking lowers it, and a note costs real interest |
| 14 | 📦🔟 Sealed grading | the premium is a **vintage** premium; grading in-print product is a mistake |

`npx vite-node scripts/verify-slimsave.mjs` round-trips every card in the catalog through the
save format and prints the size against the cloud cap.
